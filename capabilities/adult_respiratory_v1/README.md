This Phase A6 package is a versioned structural skeleton. Its population,
terminology, observation, safety, question, hypothesis, knowledge, runtime,
delivery, and evaluation assets are parseable and schema governed. Clinical
rule arrays, approved hypotheses, approved knowledge sources, and runtime
allowlists are intentionally empty until authorized review occurs.

The validator proves file completeness, closed schemas, identifiers, versions,
references, checksums, lifecycle gates, synthetic eval classification, and
Patient/Medical knowledge separation. It does not prove red-flag recall,
triage thresholds, clinical correctness, patient safety, model performance,
runtime authorization, or production readiness.

Normative-to-actual path mapping follows the directory names in this package:
`population`, `terminology`, `observations`, `safety`, `questions`,
`hypotheses`, `knowledge`, `runtime`, `delivery`, and `evals`. A6.5 legacy
asset validation and A7 Model Runtime are not started. Java/Python/TypeScript
Shared Contract bindings remain a separate A11 prerequisite.
