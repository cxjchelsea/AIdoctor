# Capability Packages

This directory contains versioned, review-gated clinical scenario packages.

`adult_respiratory_v1` is a Phase A6 structural skeleton only. It is `DRAFT`,
requires clinical review, has no approved clinical rules or knowledge sources,
is not adopted by runtime, and is blocked from production use.

Validation under `schemas/`, `validator/`, and `tests/` proves package structure,
closed references, and lifecycle gates. It does not prove clinical correctness.
