## 一、逐篇文献完整对照表

| 文献                                                         | 核心贡献（Core Contributions）                               | 主要创新点（Key Innovations）                                | 发展方向与研究空白（Future Directions & Gaps）               |
| ------------------------------------------------------------ | ------------------------------------------------------------ | ------------------------------------------------------------ | ------------------------------------------------------------ |
| **Balloch et al., 2024**Use of an Ambient AI Tool to Improve Quality of Clinical Documentation | 通过模拟真实门诊就诊流程，系统评估**环境式 AI（ambient AI）\**在临床文书生成中的效果；证明 AI 自动生成的病历与转诊信在\**完整性、结构化与整体质量**上优于人工 EHR 文书，同时显著减少医生用于文书的时间负担。 | 1️⃣ 引入“**环境式 AI**”范式：自动采集医患对话 → 去标识 → LLM 生成结构化临床文书；2️⃣ 明确区分“医生认知负担下降”与“医患交流质量未受损”；3️⃣ 在多说话人、口音差异与嘈杂环境中验证系统鲁棒性。 | ❗ 聚焦单一文书生成链路，**未引入多智能体协作**；❗ 研究基于模拟而非真实临床部署；❗ 对 hallucination、跨专科泛化与长期安全性的讨论有限；➡️ 亟需与决策支持型 MAS 融合，形成闭环系统。 |
| **Ode et al., 2025（PRISMA 系统综述）**                      | 采用 PRISMA 方法系统回顾多智能体 AI 在 **CDSS、机器人医疗、重症监护**中的应用，指出 MAS 在诊断准确性与复杂任务分解上的潜力，同时强调**真实临床验证与伦理治理不足**。 | 提出跨研究比较矩阵（性能、可扩展性、可解释性、合规性），明确“**性能提升 vs 可解释性下降**”这一结构性张力。 | 多数系统停留在概念/模拟阶段；缺乏与 EHR 的深度集成；MAS 内部协作、冲突与责任分配研究不足。 |
| **Alshehri et al., 2023（Precise Survey）**                  | 对 2015–2022 年医疗 MAS 进行系统分类，覆盖**组织管理、决策支持、数据管理、远程护理、疾病诊断**五大领域，形成全面研究地图。 | 以任务/领域为导向的大规模结构化综述（Table II/III），强调 MAS 在分布式医疗场景下的优势。 | 偏工程综述，**临床证据深度有限**；对 LLM 驱动新一代 agent 覆盖不足；伦理与治理讨论较弱。 |
| **Borkowski, 2025（观点/架构论文）**                         | 提出“下一代多智能体医疗系统”设想，以脓毒症管理为例展示多 agent 覆盖**监测—诊断—治疗—资源调度—文书**的完整链路。 | 引入**质量控制 agent、停止规则、人类介入机制**；强调 EHR/FHIR/SNOMED 互操作、区块链审计与可解释 AI。 | 以概念架构为主，**缺乏实证数据**；系统复杂度高，真实部署成本与维护性存疑；法律责任界定仍停留在原则层面。 |
| **Chen et al., 2025（eICU 实证研究）**                       | 在 eICU 数据集上实证比较 MAS 与单 agent 系统，证明 MAS 在**死亡率预测与住院时长预测**上显著优于单 agent，同时维持接近的透明度水平。 | 模块化 agent 设计（lab/vitals/context/integration/prediction/transparency/validation）；首次量化**透明度评分**并纳入系统评估。 | MAS 性能提升仍伴随轻微透明度下降；样本规模有限；agent 间通信路径的可解释性仍待增强。 |

## 二、跨文献综合后的研究版图（含 Balloch）

| 维度                 | 现有研究共识                                                 | 明确研究空白（可直接写 Gap）                                 |
| -------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| **系统形态**         | 从单点 AI（文书、预测）向多 agent 协作系统演进（Chen、Borkowski）。 | 尚未出现**ambient AI + MAS** 的统一闭环系统（感知→推理→决策→记录）。 |
| **临床价值验证**     | 多数证据来自模拟或回顾性数据。                               | 缺乏真实世界、长期、多中心临床验证（RCT）。                  |
| **医生负担与工作流** | Ambient AI 明确降低文书负担（Balloch）。                     | 尚未研究 MAS 是否进一步降低**认知与决策负担**。              |
| **可解释性与治理**   | 开始引入透明度与伦理设计（Chen、Borkowski）。                | 缺乏**可执行的伦理/责任协议**与系统级解释框架。              |
| **EHR 深度集成**     | 已强调标准（FHIR/SNOMED）。                                  | 缺少可复用的工程实现与安全写回机制。                         |
