## 可研究方向

1. **Agent 间通信路径的清晰度**：让多/单 agent 的信息流、依赖关系、因果链可追踪、可解释、可审计。
2. **评价系统（多维评估框架）**：建立覆盖性能/安全/透明度/稳定性/成本/可用性的统一评测协议与指标集。
3. **协作机制的对比**：系统对照不同多智能体协作协议（pipeline/vote/hierarchical/debate/critic等）在医疗任务上的收益与代价。
4. **质量控制、人工介入、停止规则**：把QC/stop rules/HITL设计成可量化的安全层，并评估风险降低 vs 人工负担增量。
5. **过程级评测**：从“答案对不对”升级为“证据、轨迹、动作序列、工具调用是否正确”的过程评估。
6. **人群复杂度（分层鲁棒性/公平性）**：按人群特征、共病、记录缺失等构造压力测试，评估子群体差异与公平性。
7. **任务全面性扩展**：扩展医疗agent任务覆盖（交接、用药核对、跨科室协调、随访闭环等），并验证跨任务泛化。
8. **Agent 的演化/反思/记忆更新机制**：研究何时反思、写入什么记忆、如何更新策略、如何避免错误固化。
9. **认证/监管/责任链**：面向临床部署，设计可认证、可审计、可追责的技术机制（日志、签名、责任归因、合规证明）。
10. **模型验证与“逼近真实”的方法论**：研究模型/agent如何外推到真实世界（跨环境/跨机构验证、现实约束校准、外推失效检测）。
11. **两阶段/分解式评测：检索与回答解耦**：把错误归因拆解为“取证错误”vs“推理/表达错误”，建立诊断型评测结构。
12. **长期演化 → 长期可靠性与安全控制**：从跨episode视角建模风险：错误累积、概念漂移、长期稳定性，设计冻结/回滚/更新边界。
13. **知识演化 → 知识维护型 agent 体系**：用多智能体自动构建/更新/验证/归并/发布/回滚医疗知识（图谱/知识库）并支持下游任务。
14. **隐私/脱敏作为 agent 系统的“治理层”**：把去标识化、访问控制、审计与人工复核做成输入治理/中间层，评估隐私-效用权衡。
15. **基于强化学习的可追溯诊断推理**：用RL/过程奖励训练检索-推理-诊断策略，并强化可追溯/可审计推理链。
16. **脱敏质量评测与攻防式评测基准**：构建“重识别攻击 vs 防御脱敏”的压力测试与基准，量化隐私风险与语义/任务保真。
