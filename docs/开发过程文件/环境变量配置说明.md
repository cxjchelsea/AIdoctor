# 环境变量配置说明

## 概述

项目使用**根目录的 `.env` 文件**统一管理所有环境变量，包括数据库连接、Redis配置、LLM配置等。

## 快速开始

### 步骤1：创建 .env 文件

在项目根目录创建 `.env` 文件（如果不存在）：

```bash
# Windows
copy .env.example .env

# Linux/Mac
cp .env.example .env
```

### 步骤2：配置环境变量

编辑 `.env` 文件，填入你的实际配置：

```env
# Oracle数据库配置
DB_HOST=192.168.3.25
DB_PORT=1521
DB_SERVICE=XE
DB_USERNAME=AI_DOCTOR
DB_PASSWORD=你的实际密码

# Redis配置
REDIS_HOST=localhost
REDIS_PORT=6379
REDIS_DATABASE=0

# LLM配置（Python服务使用）
LLM_BACKEND=openai
OPENAI_API_KEY=你的API密钥
...
```

### 步骤3：在IDEA中配置使用.env文件

#### 方式1：使用EnvFile插件（推荐）

1. **安装插件**
   - `File` → `Settings` → `Plugins`
   - 搜索 "EnvFile"
   - 安装 "EnvFile" 插件

2. **配置Run Configuration**
   - `Run` → `Edit Configurations`
   - 选择你的服务（如 `DiagnosisServiceApplication`）
   - 在 "EnvFile" 标签页
   - 勾选 "Enable EnvFile"
   - 添加 `.env` 文件路径：`${PROJECT_DIR}/.env`
   - 点击 `OK`

#### 方式2：手动配置环境变量

1. **打开Run Configuration**
   - `Run` → `Edit Configurations`
   - 选择你的服务

2. **配置环境变量**
   - 在 "Environment variables" 中点击 `...`
   - 手动添加所有环境变量：
     ```
     DB_HOST=192.168.3.25
     DB_PORT=1521
     DB_SERVICE=XE
     DB_USERNAME=AI_DOCTOR
     DB_PASSWORD=your_password
     ...
     ```

#### 方式3：使用启动脚本（命令行）

创建启动脚本加载.env文件：

**Windows (start.bat):**
```batch
@echo off
for /f "tokens=*" %%a in (.env) do set %%a
mvn spring-boot:run
```

**Linux/Mac (start.sh):**
```bash
#!/bin/bash
export $(cat .env | grep -v '^#' | xargs)
mvn spring-boot:run
```

## 环境变量列表

### Oracle数据库配置

| 变量名 | 说明 | 默认值 | 必需 |
|--------|------|--------|------|
| `DB_HOST` | Oracle主机地址 | `192.168.3.25` | 是 |
| `DB_PORT` | Oracle端口 | `1521` | 否 |
| `DB_SERVICE` | Oracle服务名 | `XE` | 是 |
| `DB_USERNAME` | Oracle用户名 | `AI_DOCTOR` | 是 |
| `DB_PASSWORD` | Oracle密码 | - | 是 |

### MySQL数据库配置（可选）

| 变量名 | 说明 | 默认值 |
|--------|------|--------|
| `MYSQL_HOST` | MySQL主机 | `localhost` |
| `MYSQL_PORT` | MySQL端口 | `3306` |
| `MYSQL_DATABASE` | 数据库名 | `aidoctor` |
| `MYSQL_USERNAME` | 用户名 | `root` |
| `MYSQL_PASSWORD` | 密码 | `root` |

### Redis配置

| 变量名 | 说明 | 默认值 |
|--------|------|--------|
| `REDIS_HOST` | Redis主机 | `localhost` |
| `REDIS_PORT` | Redis端口 | `6379` |
| `REDIS_DATABASE` | 数据库编号 | `0` |
| `REDIS_PASSWORD` | Redis密码 | - |

### LLM配置（Python服务）

| 变量名 | 说明 | 默认值 |
|--------|------|--------|
| `LLM_BACKEND` | LLM后端类型 | `openai` |
| `OPENAI_API_KEY` | OpenAI API密钥 | - |
| `OPENAI_MODEL` | 模型名称 | `gpt-4` |
| `OPENAI_TEMPERATURE` | 温度参数 | `0.3` |
| `OPENAI_MAX_TOKENS` | 最大token数 | `2000` |

## 配置文件说明

### 已更新的配置文件

所有服务的 `application-dev.yml` 已更新为使用环境变量：

- ✅ `diagnosis-service/src/main/resources/application-dev.yml`
- ✅ `examination-service/src/main/resources/application-dev.yml`
- ✅ `execution-trace-service/src/main/resources/application-dev.yml`

### 配置格式

```yaml
spring:
  datasource:
    url: jdbc:oracle:thin:@${DB_HOST:192.168.3.25}:${DB_PORT:1521}/${DB_SERVICE:XE}
    username: ${DB_USERNAME:AI_DOCTOR}
    password: ${DB_PASSWORD:your_password}
```

**说明：**
- `${变量名:默认值}` 格式
- 如果环境变量存在，使用环境变量的值
- 如果环境变量不存在，使用默认值

## 使用方式

### 方式1：IDEA中运行（推荐使用EnvFile插件）

1. 安装EnvFile插件
2. 配置Run Configuration使用.env文件
3. 直接运行服务

### 方式2：命令行运行

**Windows:**
```cmd
# 加载.env文件并运行
for /f "tokens=*" %a in (.env) do @set %a
cd diagnosis-service
mvn spring-boot:run
```

**Linux/Mac:**
```bash
# 加载.env文件并运行
export $(cat .env | grep -v '^#' | xargs)
cd diagnosis-service
mvn spring-boot:run
```

### 方式3：使用系统环境变量

如果不想使用.env文件，可以直接设置系统环境变量：

**Windows:**
```cmd
set DB_HOST=192.168.3.25
set DB_SERVICE=XE
set DB_USERNAME=AI_DOCTOR
set DB_PASSWORD=your_password
```

**Linux/Mac:**
```bash
export DB_HOST=192.168.3.25
export DB_SERVICE=XE
export DB_USERNAME=AI_DOCTOR
export DB_PASSWORD=your_password
```

## 注意事项

1. **.env文件不要提交到Git**
   - `.env` 文件已在 `.gitignore` 中
   - 只提交 `.env.example` 作为模板

2. **Python服务自动支持**
   - Python服务（使用pydantic）会自动读取 `.env` 文件
   - 无需额外配置

3. **Java服务需要EnvFile插件**
   - Spring Boot默认不支持.env文件
   - 需要IDEA的EnvFile插件或手动设置环境变量

4. **默认值机制**
   - 配置文件中都有默认值
   - 即使不设置环境变量，也能运行（使用默认值）
   - 但需要修改默认值为你的实际配置

## 验证配置

启动服务后，查看日志确认连接信息：

```
数据库连接成功: AI_DOCTOR@192.168.3.25:1521/XE
```

如果连接失败，检查：
1. `.env` 文件中的配置是否正确
2. IDEA的Run Configuration是否配置了EnvFile
3. 环境变量是否正确加载
