## 方案概述

### 背景

当前系统的性能监控存在以下问题：

1. **监控分散**：每个服务独立实现监控，数据分散
2. **同步阻塞**：日志写入可能阻塞业务请求
3. **缺乏统一视图**：无法统一查看所有服务的性能数据
4. **历史数据缺失**：日志文件难以进行长期趋势分析
5. **告警缺失**：无法及时发现性能问题

### 目标

建立统一的性能监控体系，实现：

- ✅ **统一监控**：所有服务的性能数据集中管理
- ✅ **非阻塞**：监控数据异步收集，不影响业务性能
- ✅ **可视化**：直观的图表展示性能趋势
- ✅ **告警机制**：自动发现性能问题并告警
- ✅ **历史分析**：支持长期趋势分析和问题回溯

```
1. 业务请求到达
   ↓
2. 中间件记录指标（内存，不阻塞）

   ↓

   ↓
5. Grafana 查询 Prometheus 展示图表
   ↓
6. AlertManager 检查告警规则，触发告警
```

## 技术选型

### 方案A: Prometheus + Grafana（推荐）

#### 技术栈

| 组件 | 技术 | 说明 |
|------|------|------|
| 指标收集 | Prometheus Client (Python/Java) | 轻量级客户端库 |
| 指标存储 | Prometheus Server | 时间序列数据库 |
| 可视化 | Grafana | 强大的可视化工具 |
| 告警 | AlertManager | Prometheus 官方告警组件 |

#### 优势

- ✅ **行业标准**：CNCF 项目，广泛使用
- ✅ **性能优秀**：客户端库极轻量，几乎无性能影响
- ✅ **功能强大**：支持多种指标类型，强大的查询语言
- ✅ **生态丰富**：大量现成的仪表板模板
- ✅ **易于部署**：Docker 一键部署

#### 劣势

- ⚠️ 需要额外部署 Prometheus 和 Grafana 服务
- ⚠️ 学习成本（PromQL 查询语言）

### 方案B: 自建监控服务

#### 技术栈

| 组件 | 技术 | 说明 |
|------|------|------|
| 监控服务 | FastAPI | Python 异步框架 |
| 数据存储 | InfluxDB / TimescaleDB | 时间序列数据库 |
| 可视化 | Grafana / 自建前端 | 可视化展示 |
| 消息队列 | Redis / RabbitMQ | 异步消息传递（可选） |

#### 优势

- ✅ **完全定制**：可以根据需求定制功能
- ✅ **技术栈统一**：使用 Python，与现有服务一致

#### 劣势

- ⚠️ 开发成本高
- ⚠️ 需要维护监控服务本身
- ⚠️ 功能可能不如 Prometheus 完善

```python
# requirements.txt
prometheus-client==0.19.0

# app/main.py
from prometheus_client import Counter, Histogram, generate_latest, REGISTRY
from prometheus_client.openmetrics.exposition import CONTENT_TYPE_LATEST
from fastapi import FastAPI, Request
from fastapi.responses import Response
import time

# 定义指标
http_requests_total = Counter(
    'http_requests_total',
    'Total HTTP requests',
    ['method', 'path', 'status']
)

http_request_duration_seconds = Histogram(
    'http_request_duration_seconds',
    'HTTP request duration in seconds',
    ['method', 'path'],
    buckets=[0.1, 0.5, 1.0, 2.0, 5.0, 10.0]  # 自定义分桶
)

http_request_errors_total = Counter(
    'http_request_errors_total',
    'Total HTTP request errors',
    ['method', 'path', 'error_type']
)

app = FastAPI()

# 性能监控中间件（非阻塞）
@app.middleware("http")
async def metrics_middleware(request: Request, call_next):
    start_time = time.time()
    method = request.method
    path = request.url.path
    
    try:
        response = await call_next(request)
        status = response.status_code
        
        # 记录指标（内存操作，几乎无性能影响）
        http_requests_total.labels(method=method, path=path, status=status).inc()
        http_request_duration_seconds.labels(method=method, path=path).observe(
            time.time() - start_time
        )
        
        return response
    except Exception as e:
        # 记录错误
        http_request_errors_total.labels(
            method=method,
            path=path,
            error_type=type(e).__name__
        ).inc()
        raise

# 暴露指标端点（Prometheus 定期拉取）
@app.get("/metrics")
async def metrics():
    return Response(
        generate_latest(REGISTRY),
        media_type=CONTENT_TYPE_LATEST
    )
```

**app/services/metrics_service.py**：

```python
"""
指标服务
"""
import asyncio
from typing import Dict, Any, List
from datetime import datetime, timedelta
from app.utils.storage import MetricsStorage

class MetricsService:
    def __init__(self):
        self.storage = MetricsStorage()
        self.metrics_buffer = []
        self.buffer_size = 100
        self.flush_interval = 5  # 5秒刷新一次

    async def store_metrics(self, metrics: Dict[str, Any]):
        """
        存储监控指标（批量写入，提高性能）
        """
        self.metrics_buffer.append({
            **metrics,
            "timestamp": datetime.now()
        })
        
        # 缓冲区满时批量写入
        if len(self.metrics_buffer) >= self.buffer_size:
            await self._flush_buffer()

    async def _flush_buffer(self):
        """刷新缓冲区到存储"""
        if self.metrics_buffer:
            await self.storage.batch_insert(self.metrics_buffer)
            self.metrics_buffer.clear()

    async def aggregate_metrics_loop(self):
        """定期聚合指标"""
        while True:
            await asyncio.sleep(self.flush_interval)
            await self._flush_buffer()
            # 执行聚合操作
            await self.storage.aggregate_metrics()

    async def query_metrics(
        self,
        service: str,
        metric_name: str,
        start_time: datetime,
        end_time: datetime,
        interval: str = "1m"
    ) -> List[Dict[str, Any]]:
        """查询指标"""
        return await self.storage.query(
            service=service,
            metric_name=metric_name,
            start_time=start_time,
            end_time=end_time,
            interval=interval
        )

    async def list_services(self) -> List[str]:
        """列出所有服务"""
        return await self.storage.list_services()

    async def get_service_summary(self, service: str) -> Dict[str, Any]:
        """获取服务摘要"""
        end_time = datetime.now()
        start_time = end_time - timedelta(hours=1)
        
        metrics = await self.query_metrics(
            service=service,
            metric_name="request_duration",
            start_time=start_time,
            end_time=end_time
        )
        
        if not metrics:
            return {}
        
        durations = [m["value"] for m in metrics]
        return {
            "service": service,
            "avg_duration": sum(durations) / len(durations),
            "max_duration": max(durations),
            "min_duration": min(durations),
            "p95_duration": sorted(durations)[int(len(durations) * 0.95)],
            "request_count": len(durations)
        }
```

#### 3. 业务服务集成

**异步发送监控数据**：

```python
# app/utils/monitoring_client.py
import aiohttp
import asyncio
from typing import Dict, Any
import logging

logger = logging.getLogger(__name__)

class MonitoringClient:
    def __init__(self, monitoring_service_url: str = "http://localhost:8090"):
        self.url = monitoring_service_url
        self.session = None
        self.queue = asyncio.Queue(maxsize=1000)
        self._sender_task = None

    async def _ensure_session(self):
        """确保HTTP会话存在"""
        if self.session is None:
            self.session = aiohttp.ClientSession(
                timeout=aiohttp.ClientTimeout(total=1)  # 快速失败
            )

    async def send_metrics_async(self, metrics: Dict[str, Any]):
        """
        异步发送监控指标（非阻塞）
        """
        try:
            await self.queue.put(metrics)
        except asyncio.QueueFull:
            logger.warning("监控指标队列已满，丢弃指标")

    async def _sender_loop(self):
        """后台发送循环"""
        await self._ensure_session()
        batch = []
        
        while True:
            try:
                # 收集一批指标
                while len(batch) < 10:
                    try:
                        metric = await asyncio.wait_for(
                            self.queue.get(),
                            timeout=1.0
                        )
                        batch.append(metric)
                    except asyncio.TimeoutError:
                        break
                
                # 批量发送
                if batch:
                    await self._send_batch(batch)
                    batch.clear()
            except Exception as e:
                logger.error(f"发送监控指标失败: {str(e)}")
                await asyncio.sleep(1)

    async def _send_batch(self, batch: List[Dict[str, Any]]):
        """批量发送指标"""
        try:
            async with self.session.post(
                f"{self.url}/api/v1/metrics/batch",
                json={"metrics": batch}
            ) as response:
                if response.status != 200:
                    logger.warning(f"监控服务返回错误: {response.status}")
        except Exception as e:
            logger.error(f"发送监控指标失败: {str(e)}")

    def start(self):
        """启动后台发送任务"""
        if self._sender_task is None:
            self._sender_task = asyncio.create_task(self._sender_loop())

    async def close(self):
        """关闭客户端"""
        if self._sender_task:
            self._sender_task.cancel()
        if self.session:
            await self.session.close()

# 全局监控客户端
monitoring_client = MonitoringClient()

# 在应用启动时启动
@app.on_event("startup")
async def startup():
    monitoring_client.start()

@app.on_event("shutdown")
async def shutdown():
    await monitoring_client.close()
```

## 最佳实践

### 1. 指标命名规范

遵循 Prometheus 命名规范：

```
<metric_name>_<suffix>
```

- `http_requests_total` - Counter，总请求数
- `http_request_duration_seconds` - Histogram，请求耗时
- `http_request_errors_total` - Counter，错误数
- `system_cpu_usage_percent` - Gauge，CPU使用率
- `system_memory_usage_bytes` - Gauge，内存使用量

### 2. 标签使用规范

使用标签区分不同维度：

```python
http_requests_total.labels(
    method="POST",
    path="/api/v1/engine/diagnose",
    status="200",
    service="diagnosis-engine"
).inc()
```

**标签原则**：
- 标签值应该是有限的、可枚举的
- 避免高基数标签（如用户ID、请求ID）
- 使用有意义的标签名

### 3. 指标类型选择

| 指标类型 | 适用场景 | 示例 |
|---------|---------|------|
| Counter | 累计计数 | 请求总数、错误总数 |
| Gauge | 当前值 | CPU使用率、内存使用量 |
| Histogram | 分布统计 | 请求耗时分布 |
| Summary | 分位数统计 | 请求耗时P95、P99 |

### 4. 采样策略

对于高频率指标，可以使用采样：

```python
import random

@app.middleware("http")
async def metrics_middleware(request: Request, call_next):
    # 采样率10%（只记录10%的请求）
    if random.random() > 0.1:
        return await call_next(request)
    
    # 记录指标...
```

### 5. 性能优化

- **批量发送**：使用批量接口减少网络请求
- **异步处理**：所有监控操作异步执行
- **快速失败**：设置短超时时间，避免阻塞
- **降级策略**：监控服务故障时不影响业务
