# 智能健康管理平台 - 技术实现方案

> **文档说明**：本文档描述智能健康管理平台的技术实现方案，包括新模块的代码结构、配置、实施步骤等。  
> **系统设计方案**：请参考《智能健康管理平台-系统设计方案.md》

## 一、技术架构

### 1.1 技术栈

- **后端框架**：Spring Boot 2.7.x / 3.2.x
- **微服务框架**：Spring Cloud
- **服务注册中心**：Nacos
- **API网关**：Spring Cloud Gateway
- **服务调用**：OpenFeign
- **数据访问**：Spring Data JPA / MyBatis Plus
- **数据库**：Oracle / PostgreSQL（共享数据库）
- **缓存**：Redis

### 1.2 当前架构特点

- 后端采用Spring Cloud Gateway + Nacos的微服务架构
- 现有服务按功能划分（dialog-service、profile-service、security-service等）
- 所有服务部署在同一环境中，通过Nacos进行服务发现
- 共享数据库（Oracle/PostgreSQL）

```yaml

  port: 8087  # family-doctor-service使用8087，diagnosis-service使用8088

spring:
  application:
    name: family-doctor-service  # 服务名称，用于Nacos注册
  
  cloud:
    nacos:
      discovery:
        server-addr: 127.0.0.1:8848  # Nacos地址
        namespace: dev
        group: DEFAULT_GROUP
  
  datasource:
    # 共享数据库配置
    driver-class-name: oracle.jdbc.driver.OracleDriver
    url: jdbc:oracle:thin:@localhost:1521/orcl
    username: your_username
    password: your_password
  
  jpa:
    hibernate:
      ddl-auto: update
    show-sql: true
    properties:
      hibernate:
        dialect: org.hibernate.dialect.Oracle12cDialect

  redis:
    host: localhost
    port: 6379
    database: 0
    timeout: 5000ms

# Feign配置
feign:
  client:
    config:
      default:
        connectTimeout: 5000
        readTimeout: 5000
```

## 五、启动类配置

### 5.1 FamilyDoctorServiceApplication.java

```java
package com.familydoctor.familydoctor;

import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;
import org.springframework.cloud.client.discovery.EnableDiscoveryClient;
import org.springframework.cloud.openfeign.EnableFeignClients;
import org.springframework.data.jpa.repository.config.EnableJpaAuditing;

import javax.annotation.PostConstruct;
import java.util.TimeZone;

/**
 * 智能家庭医生服务启动类
 * 
 * @author FamilyDoctor Team
 * @since 1.0.0
 */
@SpringBootApplication
@EnableDiscoveryClient  // 启用Nacos服务发现
@EnableFeignClients     // 启用Feign客户端
@EnableJpaAuditing      // 启用JPA审计
public class FamilyDoctorServiceApplication {

    @PostConstruct
    void setDefaultTimeZone() {
        TimeZone.setDefault(TimeZone.getTimeZone("Asia/Shanghai"));
    }

    public static void main(String[] args) {
        TimeZone.setDefault(TimeZone.getTimeZone("Asia/Shanghai"));
        SpringApplication.run(FamilyDoctorServiceApplication.class, args);
    }
}
```

## 六、服务间调用（Feign）

### 6.1 ProfileServiceClient.java

```java
package com.familydoctor.familydoctor.client;

import com.familydoctor.common.model.ApiResponse;
import com.familydoctor.profile.dto.UserProfile;
import org.springframework.cloud.openfeign.FeignClient;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.PathVariable;

/**
 * 用户档案服务客户端
 */
@FeignClient(name = "profile-service")
public interface ProfileServiceClient {
    
    @GetMapping("/api/v1/profile/{userId}")
    ApiResponse<UserProfile> getUserProfile(@PathVariable String userId);
}
```


## 七、API网关配置

### 7.1 在api-gateway的application-dev.yml中添加路由

```yaml
spring:
  cloud:
    gateway:
      routes:
        # 智能家庭医生服务
        - id: family-doctor-service
          uri: lb://family-doctor-service  # 使用服务发现
          predicates:
            - Path=/api/v1/family-doctor/**
          filters:
            - StripPrefix=0
        
        # 智能诊断服务
        - id: diagnosis-service
          uri: lb://diagnosis-service
          predicates:
            - Path=/api/v1/diagnosis/**
          filters:
            - StripPrefix=0
```
