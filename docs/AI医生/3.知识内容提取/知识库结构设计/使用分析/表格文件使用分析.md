## 二、归一化词表使用分析（7个文件）

### 2.1 symptom_normalization.csv（症状归一化词表）

| 属性 | 说明 |
|------|------|
| **表格文件名称** | `symptom_normalization.csv` |
| **文件位置** | `临床解析服务/数据/归一化词表/` |
| **对应知识内容** | 知识内容1 - 归一化词表 |
| **使用位置** | Step 1识别问题（输入归一化阶段） |
| **调用服务** | `clinical-parsing-service`<br>`health-state-assessment-service` |
| **使用方式** | 1. **系统启动时加载**：将词表加载到内存，构建倒排索引（同义词→标准术语）<br>2. **精确匹配**：在词表中查找用户输入的症状（在standard_term、synonym_1-3、alias_1-2、common_name_1-2中查找）<br>3. **模糊匹配**：如果精确匹配失败，尝试模糊匹配（部分匹配、包含匹配）<br>4. **优先级排序**：如果多个匹配结果，按`priority`字段排序，返回优先级最高的结果<br>5. **返回标准术语**：返回标准术语（`standard_term`）、标准术语ID（`standard_term_id`）、症状编码（`symptom_code`）等<br>6. **调用示例**：`normalize_symptom(user_input="胸口闷")` → 返回`{standard_term: "胸闷样不适", standard_term_id: "SYM_CHEST_DISCOMFORT_001", symptom_code: "C1234567", confidence: 1.0}` |
| **使用场景** | - 用户说"我胸口闷"<br>- 系统调用症状归一化词表，查找"胸口闷"<br>- 系统找到匹配：标准术语"胸闷样不适"（standard_term_id: "SYM_CHEST_DISCOMFORT_001"，symptom_code: "C1234567"）<br>- 系统使用"胸闷样不适"继续后续处理（查询知识图谱、生成问诊问题等） |
| **关键字段** | `standard_term`（标准术语）、`standard_term_id`（标准术语ID）、`symptom_code`（症状编码）、`priority`（匹配优先级） |
| **示例值** | 见表格文件结构设计文档第1.1节 |
