## 表头规则说明（必须写在表3顶部）

- **硬约束1：入口最多 2 个**
  任意情况下最终入口集合 **E ≤ 2**
- **硬约束2：安全优先**
  只要候选集合中出现高风险主诉 **HR**，且用户回答 **“不确定 / 说不清”**
  → 按 **H 规则**处理（并行保留 + 先走安全分流）
- **澄清目标**
  不是让用户“只能说一个症状”，而是把输入收敛为：
  - **E（入口集合，≤2）**：进入后续追问 / 推理的“问题线”
  - **S（伴随症状）**：其余症状全部保留为证据，不丢弃
- **澄清轮次上限**
  同一轮澄清最多 **2 个问题**；
  超过仍无法落位 → 直接进入兜底（LOOP）
