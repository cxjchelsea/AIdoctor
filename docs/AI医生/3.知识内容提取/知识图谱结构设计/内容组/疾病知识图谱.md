# 疾病知识图谱

## 疾病节点模板（一病一行）

| 字段（中文） | 填写说明 | 示例 |
| --- | --- | --- |
| 疾病ID | 与基础层疾病主数据关联的唯一键（不在此重复编码/同义名/分类） | DIS_DVT |
| 疾病标准名（可选） | 基础层可直接取名则可不填；内容填写更直观时保留 | 深静脉血栓形成 |
| 疾病定义与边界 | 1-2句：这是什么病；与最相近疾病边界是什么 | 静脉内血栓形成致回流受阻；不等同表浅静脉炎 |
| 典型表现模式 | 条目化：最常见的症状组合、部位特征、时间特征 | 单侧下肢肿胀；疼痛/紧绷；近期风险因素 |
| 非典型与易漏点 | 条目化：不典型但仍可能；提示不要因缺失就否定 | 早期体征不明显；可无明显疼痛 |
| 关键支持证据条目ID列表 | 引用证据条目库中最能支持本病的条目（分号分隔） | E_单侧肿胀；E_久坐久卧；E_疼痛紧绷 |
| 关键反对证据条目ID列表 | 引用明显不支持本病、会推动后移的条目 | E_双侧对称性水肿；E_明确红热痛 |
| 必须补齐的关键信息条目ID列表 | 若缺失就无法确认/排除本病的关键信息（缺口清单） | E_起病速度；E_近期手术卧床；E_是否气促胸痛 |
| 易混疾病ID列表 | 最容易混淆、需要重点鉴别的疾病（分号分隔） | DIS_蜂窝织炎；DIS_淋巴水肿；DIS_静脉曲张 |
| 关键鉴别点 | 条目化：用"维度：谁更支持谁"写清（不写问法） | 皮肤红热痛：蜂窝织炎更支持；超声血栓：本病更支持 |
| 输出依据口径 | 统一输出时证据条目数量与组织方式（简短） | 输出列3-6条关键依据 |
| 下一步建议（结构化写法） | 固定写法：追问要点；建议检查；处置建议；升级就医条件 | 追问：血栓风险；检查：下肢静脉超声；升级：胸痛气促立即就医 |
| 验证判定标准（成立/排除阈值） | 用规则/条目口径写清"满足什么算成立/基本排除"；必须包含"适用前提/阴性限制" | JD_DVT_成立_超声阳性；JD_DVT_排除_满足前提下阴性 |
| 结果回填规则 | 验证结果如何回填并改变层级/排序（置顶/后移/移出/转向子组） | FB_DVT_超声阳性置顶；FB_DVT_阴性后移并转向替代组 |
| 升级触发条件（疾病级红旗） | 命中即中断常规推理→安全兜底/升级 | ESC_DVT_胸痛或明显气促；ESC_DVT_晕厥/咯血 |
| 来源条目ID（可选） | 只填内部来源条目ID（不写书目） | REF_DVT_001 |
| 推理子组归属 | 该病主要归入哪个"线索簇/推进组"（用于挂接主诉Step3） | SG_血栓风险线索组 |
| 分流路径中的位置 | 标注默认分层/阶段（如Tier2必须优先除外） | Tier2 / must-not-miss |
| 验证计划 | 优先验证路径（追问/检查的组合路径ID列表） | VP_DVT_超声优先；VP_DVT_高危先兜底 |
| 检查价值评估 | 必要/可选/低价值 + 适用前提一句话 | 必要：下肢静脉超声（Tier2触发） |
| 回退条件 | 被反驳后退到哪里/转向哪个子组（规则ID） | RB_DVT_超声阴性→转向SG_感染炎症组 |
| 证据链构建规则 | 输出解释时证据如何选取与排序（模板/规则ID） | EXP_CHAIN_支持Top3+反对Top1 |
| 推理路径说明 | 一句话说明"为何走到这"或引用模板ID | EXP_PATH_单侧+高危→优先除外血栓 |
