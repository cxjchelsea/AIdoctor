# 知识提取 - 字段缺失与模板外内容处理方案

> **设计目标**：解决在按模板提取知识时遇到的字段缺失、需要总结归纳、模板外内容等实际问题  
> **文档版本**：v1.0  
> **适用场景**：大规模知识提取过程中的实际问题处理

---

## 📋 问题概述

在按照既定模板从医学书籍中提取知识时，会遇到以下三类实际问题：

### 1.1 问题类型

1. **字段缺失问题**：模板中定义的某个字段在书中找不到对应内容
2. **需要总结归纳问题**：书中内容分散，需要AI总结归纳才能填充到模板字段
3. **模板外内容问题**：书中存在重要信息，但模板中没有对应的字段

### 1.2 处理原则

1. **可追溯性优先**：所有内容必须可追溯到原文
2. **不允许推断**：不能生成原文中没有的内容
3. **允许合理归纳**：在可追溯的前提下，允许对分散内容进行合理归纳
4. **保留模板外信息**：模板外的重要信息应被记录和保留

## 🔍 问题一：字段缺失处理

### 2.1 字段缺失的定义

**字段缺失**：模板中定义的字段在书籍的疾病相关章节中找不到直接对应的内容。

**示例**：
- 模板字段：`流行病学.发病率`
- 书中情况：该疾病章节没有提到发病率数据

### 2.2 字段缺失的分类

#### 2.2.1 按缺失原因分类

| 缺失类型 | 原因 | 处理方式 |
|---------|------|---------|
| **真缺失** | 书中确实没有该信息 | 标记为空，记录缺失原因 |
| **隐式存在** | 信息存在但表述不同 | 尝试语义匹配和归纳 |
| **跨章节存在** | 信息在其他章节 | 扩大搜索范围 |
| **需要计算** | 信息需要从其他数据计算得出 | 标记为需要计算，记录计算依据 |

#### 2.2.2 按字段重要性分类

| 重要性 | 字段类型 | 缺失处理 |
|--------|---------|---------|
| **必填字段** | 诊断标准、治疗原则等 | 必须找到或标记为高风险缺失 |
| **重要字段** | 病因机制、临床表现等 | 尽量找到，缺失时标记 |
| **可选字段** | 流行病学、预后等 | 允许缺失，标记即可 |

### 2.3 字段缺失的处理流程

```
检测到字段缺失
    ↓
判断缺失类型
    ├─ 真缺失 → 标记为空，记录缺失原因
    ├─ 隐式存在 → 尝试语义匹配和归纳
    ├─ 跨章节存在 → 扩大搜索范围
    └─ 需要计算 → 标记为需要计算，记录计算依据
    ↓
记录缺失信息
    - 字段名称
    - 缺失原因
    - 搜索范围
    - 是否已扩大搜索
    ↓
生成缺失报告
    - 供人工审核
    - 供模板优化参考
```

### 2.4 字段缺失的处理策略

#### 2.4.1 真缺失的处理

**处理方式**：
```json
{
  "field_name": "流行病学.发病率",
  "value": null,
  "missing_reason": "书中未提及",
  "search_scope": ["第3章 心绞痛", "第1章 总论"],
  "expanded_search": true,
  "confidence": "confirmed_missing"
}
```

**记录要求**：
- 明确标记为缺失
- 记录搜索范围
- 记录是否已扩大搜索
- 标记缺失的置信度

#### 2.4.2 隐式存在的处理

**处理方式**：
- 使用语义匹配识别相关表述
- 允许合理的归纳总结
- 必须标注来源段落

**示例**：
- 模板字段：`临床表现.典型症状`
- 书中表述："患者常表现为胸痛，伴有胸闷、气短"
- 处理：归纳为"胸痛、胸闷、气短"，标注来源

#### 2.4.3 跨章节存在的处理

**处理方式**：
- 扩大搜索范围到相关章节
- 记录信息来源章节
- 标注章节关联关系

**示例**：
- 模板字段：`并发症.心律失常`
- 疾病章节未提及，但在"并发症"章节有描述
- 处理：提取并标注来源章节

### 2.5 字段缺失的数据模型

```python
class MissingField:
    """字段缺失记录"""
    field_name: str                  # 字段名称
    field_path: str                  # 字段路径（如：临床表现.典型症状）
    missing_type: str                # 缺失类型（true_missing/implicit/cross_chapter/needs_calculation）
    missing_reason: str              # 缺失原因
    search_scope: List[str]          # 搜索范围（章节列表）
    expanded_search: bool            # 是否已扩大搜索
    confidence: str                  # 缺失置信度（confirmed_missing/probably_missing/uncertain）
    suggested_action: str            # 建议操作（mark_empty/expand_search/needs_expert_review）
    detected_at: datetime            # 检测时间
```

## 📝 问题二：需要总结归纳的处理

### 3.1 总结归纳的定义

**总结归纳**：书中内容分散在多处，需要将相关内容整合后才能填充到模板字段。

**与"不允许推断"的区别**：
- **不允许推断**：不能生成原文中没有的信息
- **允许归纳**：可以将原文中分散的信息合理整合

### 3.2 总结归纳的适用场景

#### 3.2.1 可以归纳的场景

| 场景 | 说明 | 示例 |
|------|------|------|
| **列表归纳** | 将分散的列表项整合 | 将分散的症状描述整合为症状列表 |
| **段落整合** | 将相关段落整合 | 将病因机制的多个段落整合 |
| **表格转换** | 将表格内容转换为结构化数据 | 将诊断标准表格转换为JSON |
| **要点提取** | 从长段落中提取关键要点 | 从治疗原则段落中提取要点 |

#### 3.2.2 不允许归纳的场景

| 场景 | 说明 | 处理方式 |
|------|------|---------|
| **信息不存在** | 原文中没有相关信息 | 标记为缺失 |
| **需要推理** | 需要医学推理才能得出 | 标记为需要专家判断 |
| **跨疾病归纳** | 需要跨疾病信息才能得出 | 标记为需要多源融合 |

### 3.3 总结归纳的处理规则

#### 3.3.1 归纳原则

1. **可追溯性**：归纳后的内容必须能追溯到原文段落
2. **完整性**：不能遗漏原文中的关键信息
3. **准确性**：不能改变原文的语义
4. **结构化**：归纳结果应符合模板字段的结构要求

#### 3.3.2 归纳方法

**方法1：直接整合**
- 适用于：列表项、要点
- 操作：将分散的内容直接合并
- 要求：保留所有来源段落

**方法2：要点提取**
- 适用于：长段落
- 操作：提取关键信息点
- 要求：每个要点都要有来源

**方法3：结构化转换**
- 适用于：表格、图表
- 操作：转换为结构化数据
- 要求：保留原始表格/图表信息

### 3.4 总结归纳的数据模型

```python
class SummarizedField:
    """归纳字段记录"""
    field_name: str                  # 字段名称
    field_path: str                  # 字段路径
    summarized_value: Any            # 归纳后的值
    source_paragraphs: List[Dict]    # 来源段落列表
    # [
    #   {
    #     "paragraph_id": "P001",
    #     "page": 45,
    #     "chapter": "第3章 心绞痛",
    #     "content": "原文段落内容",
    #     "relevance": "high"  # 相关性（high/medium/low）
    #   }
    # ]
    summarization_method: str        # 归纳方法（direct_merge/key_points_extraction/structured_conversion）
    confidence: float                # 归纳置信度（0-1）
    needs_review: bool               # 是否需要人工审核
    review_notes: Optional[str]      # 审核意见
```

### 3.5 总结归纳的处理流程

```
检测到需要归纳的字段
    ↓
识别相关段落
    - 使用语义匹配
    - 检查段落相关性
    ↓
选择归纳方法
    ├─ 直接整合 → 合并列表项
    ├─ 要点提取 → 提取关键信息
    └─ 结构化转换 → 转换为结构化数据
    ↓
执行归纳
    - 整合内容
    - 标注来源段落
    - 计算置信度
    ↓
验证归纳结果
    - 检查可追溯性
    - 检查完整性
    - 检查准确性
    ↓
生成归纳报告
    - 供人工审核
    - 记录归纳过程
```

## 📚 问题三：模板外内容处理

### 4.1 模板外内容的定义

**模板外内容**：书籍中存在重要信息，但模板中没有对应的字段。

**示例**：
- 模板中没有"特殊人群注意事项"字段
- 但书中提到了"孕妇、儿童的特殊处理"

### 4.2 模板外内容的识别

#### 4.2.1 识别方法

1. **AI辅助识别**：
   - 在提取过程中，AI识别出重要但模板中没有的信息
   - 标记为"模板外重要内容"

2. **人工审核发现**：
   - 审核人员在审核过程中发现
   - 标记为"模板外内容"

3. **批量分析**：
   - 对已提取的数据进行批量分析
   - 识别常见但模板中没有的内容

#### 4.2.2 重要性判断

| 重要性 | 判断标准 | 处理方式 |
|--------|---------|---------|
| **高** | 影响诊断/治疗的关键信息 | 必须记录，建议模板优化 |
| **中** | 重要的补充信息 | 记录，可选模板优化 |
| **低** | 一般性信息 | 记录，暂不优化模板 |

### 4.3 模板外内容的处理策略

#### 4.3.1 临时存储策略

**设计思路**：在模板结构中增加"扩展字段"或"其他信息"字段，用于存储模板外内容。

**数据结构**：
```json
{
  "standard_fields": {
    // 标准模板字段
  },
  "extended_fields": {
    "特殊人群注意事项": {
      "value": "孕妇、儿童需要特殊处理...",
      "source": "第3章 心绞痛，第45页",
      "importance": "high",
      "suggested_field": "special_populations.notes"
    }
  }
}
```

#### 4.3.2 模板优化策略

**设计思路**：收集模板外内容，定期分析，优化模板结构。

**流程**：
```
收集模板外内容
    ↓
分析内容类型
    - 统计出现频率
    - 分析重要性
    - 识别内容模式
    ↓
提出模板优化建议
    - 新增字段建议
    - 字段结构调整建议
    ↓
专家评审
    - 医学专家评审
    - 技术团队评估
    ↓
模板版本更新
    - 创建新版本模板
    - 迁移历史数据
```

### 4.4 模板外内容的数据模型

```python
class TemplateExternalContent:
    """模板外内容记录"""
    content_id: str                  # 内容ID
    disease_id: str                  # 疾病ID
    source_id: str                   # 来源ID
    content_type: str                # 内容类型（clinical_note/special_case/warning等）
    content_text: str                 # 内容文本
    source_location: Dict            # 来源位置
    # {
    #   "page": 45,
    #   "chapter": "第3章 心绞痛",
    #   "paragraph_id": "P001"
    # }
    importance: str                  # 重要性（high/medium/low）
    frequency: int                   # 出现频率（在多本书中的出现次数）
    suggested_field: Optional[str]   # 建议的字段路径
    detected_at: datetime            # 检测时间
    reviewed: bool                   # 是否已审核
    review_decision: Optional[str]    # 审核决策（add_to_template/keep_as_extended/ignore）
```

### 4.5 模板外内容的处理流程

```
识别模板外内容
    ↓
判断重要性
    ├─ 高重要性 → 必须记录
    ├─ 中重要性 → 建议记录
    └─ 低重要性 → 可选记录
    ↓
临时存储
    - 存储到扩展字段
    - 标注来源和重要性
    ↓
定期分析
    - 统计出现频率
    - 分析内容模式
    ↓
提出优化建议
    - 新增字段建议
    - 字段结构调整
    ↓
专家评审
    - 医学专家评审
    - 决定是否优化模板
```

## 🔄 综合处理流程

### 5.1 提取阶段的处理流程

```
开始提取某个疾病
    ↓
按模板字段逐一提取
    ↓
对每个字段：
    ├─ 找到直接对应内容 → 直接提取
    ├─ 需要归纳 → 执行归纳流程
    ├─ 字段缺失 → 执行缺失处理流程
    └─ 发现模板外内容 → 执行模板外内容处理流程
    ↓
生成提取报告
    - 字段提取情况
    - 缺失字段列表
    - 归纳字段列表
    - 模板外内容列表
    ↓
进入审核阶段
```

### 5.2 审核阶段的处理

#### 5.2.1 字段缺失审核

**审核要点**：
- 确认是否真的缺失
- 检查是否遗漏了相关章节
- 判断是否需要扩大搜索范围
- 决定是否接受缺失

**审核操作**：
- 批准缺失标记
- 要求重新搜索
- 手动补充内容

#### 5.2.2 归纳结果审核

**审核要点**：
- 检查归纳是否准确
- 检查是否遗漏关键信息
- 检查来源标注是否完整
- 判断归纳是否合理

**审核操作**：
- 批准归纳结果
- 修正归纳内容
- 要求重新归纳

#### 5.2.3 模板外内容审核

**审核要点**：
- 判断内容重要性
- 决定是否添加到模板
- 评估对现有数据的影响

**审核操作**：
- 保留为扩展字段
- 提出模板优化建议
- 忽略（如果重要性低）

## 🎯 实际应用示例

### 7.1 示例：心绞痛知识提取

**场景**：从《内科学》第9版提取"心绞痛"的知识

#### 7.1.1 字段缺失示例

**字段**：`流行病学.发病率`

**处理过程**：
1. 搜索疾病章节，未找到发病率数据
2. 扩大搜索到"总论"章节，仍未找到
3. 标记为缺失：
```json
{
  "field_name": "流行病学.发病率",
  "value": null,
  "missing_reason": "书中未提及",
  "search_scope": ["第3章 心绞痛", "第1章 总论"],
  "expanded_search": true,
  "confidence": "confirmed_missing"
}
```

#### 7.1.2 需要归纳示例

**字段**：`临床表现.典型症状`

**原文内容**（分散在多处）：
- 第45页："患者常表现为胸痛"
- 第46页："可伴有胸闷、气短"
- 第47页："部分患者出现心悸"

**处理过程**：
1. 识别相关段落
2. 归纳整合：
```json
{
  "field_name": "临床表现.典型症状",
  "value": ["胸痛", "胸闷", "气短", "心悸"],
  "source_paragraphs": [
    {"page": 45, "content": "患者常表现为胸痛"},
    {"page": 46, "content": "可伴有胸闷、气短"},
    {"page": 47, "content": "部分患者出现心悸"}
  ],
  "summarization_method": "direct_merge",
  "confidence": 0.95
}
```

#### 7.1.3 模板外内容示例

**发现内容**："孕妇心绞痛的特殊处理"

**处理过程**：
1. 识别为模板外内容
2. 判断重要性：高（影响治疗）
3. 临时存储：
```json
{
  "extended_fields": {
```

## 📝 实施建议

### 8.1 模板设计建议

1. **字段分类**：
   - 必填字段：诊断标准、治疗原则等
   - 重要字段：病因机制、临床表现等
   - 可选字段：流行病学、预后等

2. **扩展字段设计**：
   - 在模板中预留"扩展字段"或"其他信息"字段
   - 用于存储模板外内容

3. **字段说明**：
   - 每个字段都要有清晰的说明
   - 说明字段的含义、数据格式、来源要求

### 8.2 提取流程建议

1. **分阶段提取**：
   - 第一阶段：直接提取（能找到直接对应的）
   - 第二阶段：归纳提取（需要归纳的）
   - 第三阶段：缺失处理（找不到的）

2. **质量控制**：
   - 对归纳结果进行置信度评估
   - 对缺失字段进行重要性评估
   - 对模板外内容进行重要性评估

3. **审核机制**：
   - 归纳结果必须审核
   - 重要字段缺失必须审核
   - 高重要性模板外内容必须审核

### 8.3 模板优化建议

1. **定期分析**：
   - 定期分析缺失字段模式
   - 定期分析模板外内容
   - 识别模板优化机会

2. **版本管理**：
   - 模板版本化管理
   - 记录模板变更历史
   - 支持数据迁移

3. **专家评审**：
   - 模板优化需要医学专家评审
   - 评估对现有数据的影响
   - 制定数据迁移方案
