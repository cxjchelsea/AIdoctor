# AI医生系统 - 知识内容提取分工计划

> **分工原则**：内容组负责找权威数据源和医学知识准确性，技术组负责格式设计、提取、清洗、导入的技术实现，双方共同确定字段定义和知识图谱结构。

---

## 一、总体分工原则

### 1.1 分工角色

**内容组**：

- 负责找权威数据源、书籍
- 负责医学知识内容的准确性
- 负责审核提取、清洗、导入结果的医学准确性

**技术组**：

- 负责确定数据格式规范
- 负责编写提取、清洗、导入脚本
- 负责技术实现和性能优化

**共同协作**：
- 共同确定字段定义和知识图谱结构
- 共同审核结构设计是否符合医学逻辑和技术需求

---

### 1.2 工作流程

```
阶段1：共同确定结构
  ↓
阶段2：内容组找权威数据源
  ↓
阶段3：技术组确定格式并进行提取、清洗、导入
  ↓
阶段4：内容组审核结果，技术组修正（持续迭代）
```

## 五、19个知识内容项的具体分工

### 5.1 处理优先级说明（先做核心层）

**优先级定义**：
- **P0（最高优先级）**：系统核心功能必需，必须先完成，其他内容依赖它
- **P1（高优先级）**：重要功能，在P0完成后优先处理

**依赖关系分析**：

| 层级 | 依赖关系 | 说明 |
|------|---------|------|
| **基础层** | 无依赖 | 提供标准化底座（编码、词表、标准配置、目录） |
| **核心层** | 部分依赖基础层 | 需要引用标准术语和编码，但可以使用临时编码先做 |
| **规则层** | 依赖核心层 | 需要核心层的模板才能工作 |

**采用方案：先做核心层（快速验证MVP）**

**处理顺序**：
1. **第一批（P0核心层-最小可行版本）**：5、6、7 - 先做核心功能，使用临时编码
2. **第二批（P0基础层-核心部分）**：0、1、3 - 补充标准编码和词表，替换临时编码
3. **第三批（P0基础层-补充）**：2 - 补充基础标准配置
4. **第四批（P0规则层-核心）**：8、9、10、11、12、13、17、18 - 核心规则，依赖核心层
5. **第五批（P1辅助功能）**：4、14、15、16 - 辅助功能，可以稍后处理
