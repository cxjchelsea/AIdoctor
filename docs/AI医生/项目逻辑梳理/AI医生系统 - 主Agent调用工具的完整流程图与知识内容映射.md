# AI医生系统 - 主Agent调用工具的完整流程图与知识内容映射

> **文档定位**：本文档详细说明AI医生系统中主Agent调用工具的完整流程，以及各流程阶段使用的知识内容映射。  
> **架构原则**：单主Agent + 多工具Tools + CDP + 审计

---

## 一、系统整体架构流程图

## 七、总结

### 7.1 主Agent调用工具的流程特点

1. **主Agent是唯一决策者**：
   - 主Agent决定调用哪些工具
   - 主Agent决定是否接受工具的suggestedWrites
   - 主Agent进行evidence fusion和conflict resolution
   - 主Agent是唯一可以写入CDP的服务

2. **工具无状态、无独立目标**：
   - 工具从CDP读取输入
   - 工具返回suggestedWrites
   - 工具不直接写入CDP
   - 工具内部调用知识库

3. **CDP唯一事实源**：
   - 所有工具从CDP读取输入
   - 所有工具返回的结果通过主Agent写入CDP
   - CDP是系统内部一切推理的核心数据结构

4. **知识内容在工具内部调用**：
   - 知识库不是独立服务，而是工具的内部资源
   - 工具从CDP读取输入，调用知识库，返回结构化结果
   - 知识库调用记录到evidence中

### 7.2 知识内容映射总结

- **知识内容存储在工具内部**：知识图谱、配置文件、表格文件
- **工具调用知识库**：工具内部调用知识库，返回结构化结果
- **主Agent写入CDP**：主Agent根据工具的suggestedWrites写入CDP
- **AuditTrail记录**：所有知识库调用记录到AuditTrail
