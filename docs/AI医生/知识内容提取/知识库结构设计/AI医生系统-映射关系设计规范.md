## 二、核心映射关系设计

### 2.1 主诉↔症状映射（CONTAINS）

#### 2.1.1 关系定义

**关系类型**：`CONTAINS`  
**起点实体**：`ChiefComplaint`（主诉）  
**终点实体**：`Symptom`（症状）  
**存储位置**：知识图谱（Neo4j）  
**关系语义**：主诉包含哪些症状，表示主诉自然语言表达映射为标准医学症状

#### 2.1.2 关系属性

| 属性名 | 数据类型 | 是否必填 | 取值范围 | 说明 | 示例 |
|-------|---------|---------|---------|------|------|
| **mapping_type** | String | ✅ | direct/partial/contextual/ambiguous | 映射类型 | direct |
| **example_statements** | String[] | ✅ | - | 示例语句，用户可能使用的自然语言表达 | ["心口堵", "胸口闷", "胸口堵得慌"] |
| **explanation** | String | ✅ | - | 映射说明，解释为什么这样映射 | "心口堵"通常指胸闷样不适，需要进一步确认是否为胸痛 |
| **source** | String | ✅ | - | 依据来源，医学文献或专家共识 | "Murtagh's General Practice Chapter 5" |
| **version** | String | ✅ | v主版本.次版本 | 版本号 | v1.0 |
| **status** | String | ✅ | active/deprecated/pending | 状态 | active |
| **created_at** | DateTime | ✅ | - | 创建时间 | 2026-01-28T00:00:00Z |
| **updated_at** | DateTime | ✅ | - | 更新时间 | 2026-01-28T00:00:00Z |
| **created_by** | String | ✅ | - | 创建人 | user_001 |
| **reviewed_by** | String | ✅ | - | 审核人 | doctor_001 |
| **reviewed_at** | DateTime | ✅ | - | 审核时间 | 2026-01-29T00:00:00Z |

#### 2.1.3 映射类型说明

| 映射类型 | 说明 | 示例 |
|---------|------|------|
| **direct** | 直接映射，主诉与症状高度一致 | "胸痛" → "胸痛" |
| **partial** | 部分映射，主诉包含症状但不完全一致 | "胸口闷" → "胸闷样不适" |
| **contextual** | 上下文映射，需要结合上下文才能确定 | "心口堵" → "胸闷样不适"（需要确认是否为胸痛） |
| **ambiguous** | 模糊映射，存在歧义，需要进一步确认 | "胸口不舒服" → "胸闷样不适"或"胸痛" |

#### 2.1.4 映射数量约束

| 映射类型 | 允许数量 | 说明 |
|---------|---------|------|
| **direct** | 1-2个 | 直接映射的症状，必须包含 |
| **partial** | ≤3个 | 部分映射的症状，建议包含 |
| **contextual/ambiguous** | ≤2个 | 上下文或模糊映射的症状，谨慎包含 |
| **总映射数** | ≤5个 | 每个主诉最多映射5个症状 |

#### 2.1.5 Neo4j Cypher示例

```cypher
// 创建主诉↔症状映射关系
MATCH (cc:ChiefComplaint {display_id: 'CC_CHEST_PAIN'})
MATCH (s:Symptom {display_id: 'SYM_CHEST_DISCOMFORT_001'})
MERGE (cc)-[r:CONTAINS {
    mapping_type: 'partial',
    example_statements: ['心口堵', '胸口闷', '胸口堵得慌'],
    explanation: '"心口堵"通常指胸闷样不适，需要进一步确认是否为胸痛',
    source: 'Murtagh\'s General Practice Chapter 5',
    version: 'v1.0',
    status: 'active',
    created_at: datetime(),
    updated_at: datetime(),
    created_by: 'user_001',
    reviewed_by: 'doctor_001',
    reviewed_at: datetime()
}]->(s)
RETURN r
```

### 2.2 症状→疾病映射（HAS_CANDIDATE_DISEASE）

#### 2.2.1 关系定义

**关系类型**：`HAS_CANDIDATE_DISEASE`  
**起点实体**：`Symptom`（症状）  
**终点实体**：`Disease`（疾病）  
**存储位置**：知识图谱（Neo4j）  
**关系语义**：症状提示可能的疾病，用于构建鉴别诊断候选集

#### 2.2.2 关系属性

| 属性名 | 数据类型 | 是否必填 | 取值范围 | 说明 | 示例 |
|-------|---------|---------|---------|------|------|
| **polarity** | String | ✅ | support/exclude | 关系方向，支持或排除疾病 | support |
| **typicality** | String | ✅ | typical/atypical | 典型性，症状对疾病的典型程度 | typical |
| **evidence_level** | String | ✅ | strong/moderate/weak | 证据等级，医学证据的强度 | strong |
| **explanation** | String | ✅ | - | 医学解释，解释为什么症状提示该疾病 | "胸痛是心绞痛的典型症状，活动后加重" |
| **evidence_source** | String | ✅ | - | 依据来源，医学文献或指南 | "Harrison's Principles of Internal Medicine Chapter 237" |
| **version** | String | ✅ | v主版本.次版本 | 版本号 | v1.0 |
| **status** | String | ✅ | active/deprecated/pending | 状态 | active |
| **created_at** | DateTime | ✅ | - | 创建时间 | 2026-01-28T00:00:00Z |
| **updated_at** | DateTime | ✅ | - | 更新时间 | 2026-01-28T00:00:00Z |
| **created_by** | String | ✅ | - | 创建人 | user_001 |
| **reviewed_by** | String | ✅ | - | 审核人 | doctor_001 |
| **reviewed_at** | DateTime | ✅ | - | 审核时间 | 2026-01-29T00:00:00Z |

#### 2.2.3 Polarity（关系方向）说明

| Polarity | 说明 | 示例 |
|---------|------|------|
| **support** | 支持疾病，症状提示该疾病 | "胸痛" → "心绞痛"（支持） |
| **exclude** | 排除疾病，症状不支持该疾病 | "无胸痛" → "心绞痛"（排除） |

#### 2.2.4 Typicality（典型性）说明

| Typicality | 说明 | 示例 |
|-----------|------|------|
| **typical** | 典型症状，该疾病的常见表现 | "胸痛" → "心绞痛"（典型） |
| **atypical** | 非典型症状，该疾病的少见表现 | "腹痛" → "心绞痛"（非典型，但可能） |

#### 2.2.5 鉴别诊断结构要求

每个症状的疾病候选必须覆盖三类：

| 疾病类型 | 说明 | 必须包含 | 示例 |
|---------|------|---------|------|
| **常见病** | 该症状最常见的疾病 | ✅ 必须 | "胸痛" → "心绞痛"、"胃食管反流" |
| **危险病** | 该症状可能提示的严重疾病，即使概率低也必须考虑 | ✅ 必须 | "胸痛" → "急性心肌梗死"、"肺栓塞" |
| **良性/自限性** | 该症状可能提示的良性或自限性疾病 | ✅ 建议 | "胸痛" → "肋间神经痛"、"功能性胸痛" |

#### 2.2.6 映射数量约束

| 关系方向 | 允许数量 | 说明 |
|---------|---------|------|
| **support关系** | 3-8个 | 支持该疾病的候选，必须覆盖常见病、危险病、良性/自限性 |
| **exclude关系** | ≤3个 | 排除该疾病的候选，用于排除诊断 |
| **总候选数** | ≤10个 | 每个症状最多10个疾病候选 |

## 四、映射规范

| 映射类型 | 说明 | 使用场景 | 示例 |
|---------|------|---------|------|
| **direct** | 直接映射，主诉与症状高度一致 | 主诉直接对应标准症状 | "胸痛" → "胸痛" |
| **partial** | 部分映射，主诉包含症状但不完全一致 | 主诉是症状的常见表达 | "胸口闷" → "胸闷样不适" |
| **contextual** | 上下文映射，需要结合上下文才能确定 | 主诉需要结合其他信息才能确定症状 | "心口堵" → "胸闷样不适"（需要确认是否为胸痛） |
| **ambiguous** | 模糊映射，存在歧义，需要进一步确认 | 主诉存在多种可能的症状解释 | "胸口不舒服" → "胸闷样不适"或"胸痛" |

## 五、关系属性规范

### 5.1 通用属性

所有映射关系都必须包含以下通用属性：

| 属性名 | 数据类型 | 是否必填 | 说明 |
|-------|---------|---------|------|
| **version** | String | ✅ | 版本号，格式：v主版本.次版本 |
| **status** | String | ✅ | 状态：active/deprecated/pending |
| **created_at** | DateTime | ✅ | 创建时间 |
| **updated_at** | DateTime | ✅ | 更新时间 |
| **created_by** | String | ✅ | 创建人 |
| **reviewed_by** | String | ✅ | 审核人 |
| **reviewed_at** | DateTime | ✅ | 审核时间 |

### 5.2 版本号规范

**版本号格式**：`v主版本.次版本`

- **主版本**：重大变更（如映射关系结构变更、属性变更）
- **次版本**：小幅调整（如属性值更新、映射关系调整）

**示例**：
- `v1.0`：初始版本
- `v1.1`：属性值更新
- `v2.0`：关系结构变更

### 5.3 状态规范

| 状态 | 说明 | 使用场景 |
|-----|------|---------|
| **active** | 激活状态，正常使用 | 已审核通过的映射关系 |
| **deprecated** | 已废弃，不再使用 | 被新版本替代的映射关系 |
| **pending** | 待审核，未激活 | 新创建但未审核的映射关系 |
