# AI医生系统 - 系统边界与合规定位规范

> **文档定位**：定义AI医生系统的边界、合规要求、适用场景和禁用场景，确保系统在合法合规的范围内运行，保障用户安全和系统责任边界。

> **重要理解**：本文档是**对知识内容的限制与约束**，而非知识内容本身。
>
> - **知识内容**（19项）：系统的"知识资产"，包括症状、疾病、证据、规则等医学知识
> - **系统边界**（本文档）：系统的"约束规则"，限制系统如何使用这些知识内容

---

## 一、系统定位声明

### 1.1 核心定位

**AI医生系统的定位**：**诊断支持 + 风险分级 + 就医建议系统**

**不是**：
- ❌ 不是"诊断系统"（不直接下诊断）
- ❌ 不是"治疗系统"（不给出具体用药建议）
- ❌ 不是"替代医生"（不替代专业医生的诊断和治疗）

**是**：
- ✅ **诊断支持系统**：提供专业的可能性分析、鉴别诊断、检查建议
- ✅ **风险分级系统**：识别高危情况，进行风险分级，提供紧急程度判断
- ✅ **就医建议系统**：建议何时就医、去哪个专科、需要带什么资料

### 1.2 功能边界

#### 1.2.1 系统可以做什么

| 功能 | 说明 | 示例 |
|------|------|------|
| **可能性分析** | 提供按可能性排序的疾病方向（Top 3-5） | "根据您的症状，最可能的情况是：1. 心绞痛（可能性较高）2. 胃食管反流（可能性中等）3. 肋间神经痛（可能性较低）" |
| **鉴别诊断** | 提供支持证据、反对证据、鉴别要点 | "支持心绞痛的证据：胸痛、活动后加重；反对心绞痛的证据：无典型心电图表现" |
| **检查建议** | 建议做哪些检查、检查的优先级、检查的目的 | "建议优先做心电图检查，用于排除急性心肌梗死" |
| **风险分级** | 识别高危情况，判断紧急程度 | "您的情况属于高风险，建议立即就医" |
| **就医建议** | 建议何时就医、去哪个专科、需要带什么资料 | "建议3天内到心内科就诊，请携带既往检查报告" |
| **健康管理** | 针对无症状人群，提供健康筛查、体检规划、健康管理建议 | "根据您的年龄和性别，建议每年做一次血常规检查" |

#### 1.2.2 系统不能做什么

| 禁止功能 | 说明 | 示例 |
|---------|------|------|
| **确诊式表述** | 不能使用"您得了XX病"、"一定是XX病"等绝对化表述 | ❌ "您得了心绞痛" ❌ "一定是急性心肌梗死" |
| **具体用药建议** | 不能给出具体的用药剂量和疗程 | ❌ "建议服用硝酸甘油0.5mg，每日3次" ✅ "建议在医生指导下使用硝酸甘油类药物" |
| **手术建议** | 不能给出具体的手术方案 | ❌ "建议立即进行冠状动脉介入治疗" ✅ "可能需要手术治疗，具体方案需由医生根据检查结果决定" |
| **替代医生诊断** | 不能替代专业医生的最终诊断 | ❌ "根据我的分析，您的诊断是XX病" ✅ "本分析仅供参考，最终诊断需由专业医生确定" |
| **急危重症处理** | 不能处理急危重症，必须立即建议就医 | ❌ 继续问诊流程 ❌ 给出观察建议 ✅ 立即建议就医 |

### 1.3 输出口径

**标准输出口径**：**"诊断支持 + 风险分级 + 就医建议"**

**输出格式要求**：
- ✅ 使用"可能性"、"可能"、"考虑"等非绝对化表述
- ✅ 提供多个可能性，按可能性排序
- ✅ 明确标注"本分析仅供参考，不替代医生诊断"
- ✅ 提供明确的就医建议和危险信号提示

## 二、适用人群

### 2.1 适用人群分类

| 人群类型 | 适用场景 | 说明 |
|---------|---------|------|
| **成人（18-65岁）** | ✅ 完全适用 | 系统主要针对成人设计，所有功能均适用 |
| **老年（65岁以上）** | ✅ 适用（需特殊标注） | 适用，但需要考虑老年人群的特殊性（合并症多、症状不典型等） |
| **青少年（14-18岁）** | ⚠️ 部分适用 | 适用，但需要考虑青少年人群的特殊性（生长发育、心理因素等） |
| **儿童（3-14岁）** | ⚠️ 限制适用 | 仅适用于常见症状的初步判断，必须建议就医 |
| **婴幼儿（0-3岁）** | ❌ 不适用 | 系统不适用于婴幼儿，必须立即建议就医 |

### 2.2 适用场景分类

| 场景类型 | 适用情况 | 说明 |
|---------|---------|------|
| **健康管理** | ✅ 完全适用 | 针对无症状人群，提供健康筛查、体检规划、健康管理建议 |
| **症状初筛** | ✅ 完全适用 | 针对有症状人群，提供可能性分析、鉴别诊断、检查建议 |
| **检查结果解读** | ✅ 完全适用 | 针对检查结果异常，提供可能性分析、进一步检查建议 |
| **慢病管理** | ⚠️ 部分适用 | 适用于慢病的监测和管理，但不替代医生的治疗方案调整 |
| **急危重症** | ❌ 不适用 | 系统不适用于急危重症，必须立即建议就医 |

### 2.3 人群字段标准

**人群字段定义**（对应**基础层第2项：基础标准配置**）：

| 字段 | 取值范围 | 说明 |
|------|---------|------|
| **年龄** | 0-120岁 | 必须明确年龄，用于判断适用人群 |
| **性别** | 男/女/其他 | 必须明确性别，用于疾病可能性分析 |
| **人群类型** | 成人/老年/青少年/儿童/婴幼儿 | 根据年龄自动判断，用于适用性检查 |
| **适用性标志** | 完全适用/部分适用/限制适用/不适用 | 根据人群类型和场景自动判断 |

## 三、禁用场景

### 3.1 绝对禁用场景

以下场景**绝对禁止**使用系统进行诊断分析，必须立即建议就医：

| 禁用场景 | 说明 | 处理方式 | 示例 |
|---------|------|---------|------|
| **急危重症** | 任何急危重症情况 | 立即建议就医，不进行诊断分析 | "胸痛伴大汗、气短" → 立即建议急诊就医 |
| **妊娠期** | 妊娠期任何症状 | 立即建议就医，不进行诊断分析 | "妊娠20周，腹痛" → 立即建议产科就医 |
| **婴幼儿（0-3岁）** | 3岁以下婴幼儿任何症状 | 立即建议就医，不进行诊断分析 | "1岁婴儿，发热" → 立即建议儿科急诊 |
| **意识障碍** | 任何意识障碍情况 | 立即建议就医，不进行诊断分析 | "患者意识不清" → 立即建议急诊就医 |
| **严重外伤** | 任何严重外伤情况 | 立即建议就医，不进行诊断分析 | "车祸后胸痛" → 立即建议急诊就医 |
| **药物中毒** | 任何药物中毒情况 | 立即建议就医，不进行诊断分析 | "误服药物后不适" → 立即建议急诊就医 |

### 3.2 相对禁用场景（需特殊处理）

以下场景**需要特殊处理**，系统可以进行分析，但必须加强风险提示：

| 场景 | 说明 | 处理方式 | 示例 |
|------|------|---------|------|
| **老年人群（65岁以上）** | 老年人群症状不典型，合并症多 | 加强高危识别，降低诊断停止阈值 | "70岁男性，胸痛" → 必须排除急性心肌梗死 |
| **儿童（3-14岁）** | 儿童症状可能不典型 | 仅提供初步判断，必须建议就医 | "8岁儿童，发热" → 建议儿科就医 |
| **合并多种疾病** | 患者合并多种疾病 | 加强鉴别诊断，考虑疾病相互作用 | "糖尿病患者，胸痛" → 需要特别关注心血管风险 |
| **免疫功能低下** | 免疫功能低下人群 | 加强感染风险识别 | "化疗后，发热" → 需要特别关注感染风险 |

## 四、合规话术模板

### 4.1 标准免责声明

**必须包含的免责声明**（所有输出都必须包含）：

```
本分析仅供参考，不替代医生诊断。最终诊断需由专业医生根据完整病史、体格检查和辅助检查结果确定。如出现紧急情况，请立即就医。
```

### 4.2 输出话术模板

#### 4.2.1 可能性分析话术

**标准格式**：
```
根据您描述的症状，最可能的情况是：

1. [疾病名称]（可能性[较高/中等/较低]）
   - 支持证据：[证据1]、[证据2]
   - 反对证据：[证据1]、[证据2]
   - 建议：[检查建议/就医建议]

2. [疾病名称]（可能性[较高/中等/较低]）
   ...

【重要提示】
本分析仅供参考，不替代医生诊断。建议您[就医建议]。
```

**示例**：
```
根据您描述的症状，最可能的情况是：

1. 心绞痛（可能性较高）
   - 支持证据：胸痛、活动后加重、休息后缓解
   - 反对证据：无典型心电图表现
   - 建议：建议做心电图检查，3天内到心内科就诊

2. 胃食管反流（可能性中等）
   - 支持证据：胸痛、与进食相关
   - 反对证据：无反酸、烧心症状
   - 建议：建议做胃镜检查，可预约消化内科

【重要提示】
本分析仅供参考，不替代医生诊断。建议您3天内到心内科就诊，请携带既往检查报告。
```

```
【高风险提示】
您的情况属于高风险，可能存在严重疾病，建议立即就医。

危险信号：
- [危险信号1]
- [危险信号2]

建议：
- 立即到[专科]急诊就诊
- 如出现[症状加重情况]，请立即拨打120

【重要提示】
```

**中风险话术**：
```

- 建议做[检查项目]检查

【重要提示】
```

**低风险话术**：
```

【重要提示】
本分析仅供参考，不替代医生诊断。如症状持续或加重，请及时就医。
```

### 4.3 禁止使用的话术

**绝对禁止的话术**：

| 禁止话术 | 正确话术 |
|---------|---------|
| ❌ "您得了XX病" | ✅ "最可能的情况是XX病" |
| ❌ "一定是XX病" | ✅ "考虑XX病的可能性较高" |
| ❌ "确诊为XX病" | ✅ "可能性分析提示XX病" |
| ❌ "建议服用XX药物，每日X次，每次Xmg" | ✅ "建议在医生指导下使用XX类药物" |
| ❌ "不需要就医" | ✅ "可以观察，如症状持续或加重，建议就医" |
| ❌ "没有问题" | ✅ "目前症状可能不需要紧急处理，但建议进一步检查" |

## 五、输出边界规范

### 5.1 输出内容边界

#### 5.1.1 必须输出的内容

| 输出项 | 说明 | 是否必填 |
|-------|------|---------|
| **可能性分析** | 按可能性排序的疾病方向（Top 3-5） | ✅ 必填 |
| **支持证据** | 详细的症状/体征/检查结果支持证据 | ✅ 必填 |
| **反对证据** | 详细的反对证据和鉴别要点 | ⚠️ 重要 |
| **缺失信息** | 还需要哪些关键信息来进一步判断 | ⚠️ 重要 |
| **检查建议** | 专业的检查建议（检查项目、优先级、目的） | ✅ 必填 |
| **就医建议** | 建议何时就医、去哪个专科、需要带什么资料 | ✅ 必填 |

| **免责声明** | 标准免责声明 | ✅ 必填 |

#### 5.1.2 禁止输出的内容

| 禁止输出项 | 说明 | 替代方案 |
|-----------|------|---------|
| **确诊式表述** | "您得了XX病"、"一定是XX病" | 使用"可能性分析"、"考虑XX病" |
| **具体用药剂量** | 具体的用药剂量和疗程 | 只提示药物类别，建议在医生指导下使用 |
| **手术建议** | 具体的手术方案 | 只提示"可能需要手术治疗"，具体方案由医生决定 |
| **替代医生诊断** | "根据我的分析，您的诊断是XX病" | 使用"可能性分析"、"建议进一步检查" |

## 六、与19项知识内容的关系

### 6.1 关系定位

**重要理解**：
- **19项知识内容**：是系统的"知识资产"，包括症状、疾病、证据、规则等医学知识
- **系统边界与合规定位**：是系统的"约束规则"，限制系统如何使用这些知识内容

**关系说明**：
- 系统边界**不是**知识内容本身，而是**对知识内容的约束**
- 系统边界**约束**系统如何使用19项知识内容进行诊断分析
- 系统边界**确保**系统在合法合规的范围内使用知识内容

### 6.2 约束关系表

| 系统边界约束项 | 约束的知识内容 | 约束方式 | 说明 |
|--------------|--------------|---------|------|
| **系统定位声明** | 规则层第13项：输出规则 | 约束输出格式和口径 | 限制系统如何使用输出规则，确保不越界 |
| **适用人群** | 基础层第2项：基础标准配置 | 约束人群字段的使用范围 | 限制系统对哪些人群使用知识内容 |
| **禁用场景识别** | 规则层第12项：风险与急症识别规则 | 约束风险识别的触发条件 | 限制系统在禁用场景下使用知识内容 |
| **禁用场景处理** | 规则层第18项：安全兜底规则 | 约束安全兜底规则的执行 | 限制系统在禁用场景下的行为 |
| **合规话术模板** | 规则层第13项：输出规则 | 约束输出话术的格式 | 限制系统如何表达诊断结果 |
| **输出边界规范** | 所有知识内容 | 约束所有知识内容的输出方式 | 限制系统如何输出知识内容的结果 |

### 6.3 建议的存储位置

**建议归属**：**规则层第18项"安全兜底规则"的扩展**，或作为**系统级约束配置**独立存在

**原因**：
- 系统边界是"规则"和"约束"，不是"知识内容"
- 属于"安全保障"范畴，与第18项"安全兜底规则"性质相同
- 可以独立存在，作为系统级的约束配置

**存储形式**：**配置文件**

**存储位置**：
- 主配置文件：`configs/system_boundary/system_boundary_config.json`
- 话术模板：`configs/system_boundary/compliance_templates.json`
- 禁用场景规则：`configs/rules/safety_fallback_rules.json`（扩展第18项）
