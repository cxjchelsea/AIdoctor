## 主诉表2｜最小关键字段配置表（一行 = 1 个信息点）

| 信息点         | 必填等级 | 标准问法（原话）                      | 答案口径（简写）                 | 缺失处理     |
| -------------- | -------- | ------------------------------------- | -------------------------------- | ------------ |
| 起病时间与过程 | 必须     | 什么时候开始的？突然还是慢慢加重？    | 突然 / 渐进 / 不确定 + 时长      | 必须补齐     |
| 部位 / 范围    | 必须     | 具体哪里不舒服？是一点还是一片？      | 标准部位（可多选）               | 必须补齐     |
| 分布           | 必须     | 是一侧明显还是两侧差不多？            | 单侧 / 双侧 / 局部 / 不确定      | 必须补齐     |
| 性质           | 必须     | 更像刺痛、压着、灼烧还是闷胀？        | 固定词 + 不确定                  | 必须补齐     |
| 严重度         | 必须     | 0 到 10 分你给几分？                  | 0–10 / 不确定                    | 必须补齐     |
| 诱因           | 重要     | 什么情况下出现或加重？                | 运动 / 进食 / 体位 / 情绪 / 外伤 | 可继续但降级 |
| 缓解因素       | 重要     | 休息或用药后会缓解吗？                | 有 / 无 / 不确定                 | 可继续但降级 |
| 伴随症状       | 重要     | 同时还有哪些不适？                    | 3–5 个标准症状                   | 可继续但降级 |
| 关键背景       | 重要     | 有相关既往史 / 用药 / 妊娠 / 暴露吗？ | 有 / 无 / 不确定                 | 可继续但降级 |
| 危险信号自检   | 必须     | 有没有晕厥 / 大汗 / 明显呼吸困难？    | 有 / 无 / 不确定                 | 命中走兜底   |
