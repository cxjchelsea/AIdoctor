# 证据条目清单与提取指南

## 一、证据条目的组织方式

### 1.1 证据条目库的特点

**证据条目库与主诉、疾病的区别**：
- **主诉知识图谱**：按主诉组织，一个主诉一张表（如：胸痛一张表、发热一张表）
- **疾病知识图谱**：按疾病组织，一个疾病一张表（如：急性心肌梗死一张表、稳定型心绞痛一张表）
- **证据条目知识图谱**：按证据类型组织，**每行一个证据**（如：胸痛伴大汗一个证据、心电图ST段抬高一个证据）

**证据条目库的组织结构**：
- 不是按疾病或主诉分类，而是按**证据类型**分类：
  - **症状类证据**（如：胸痛伴大汗、发热、腹痛）
  - **体征类证据**（如：皮肤苍白、呼吸急促、腹部压痛）
  - **检查结果类证据**（如：心电图ST段抬高、血常规异常、CT显示占位）
  - **测量值类证据**（如：体温、血压、心率、血氧饱和度）
  - **人群背景类证据**（如：年龄>40岁、有糖尿病史、近期手术史）

### 1.2 为什么需要证据条目清单？

证据条目不像主诉和疾病那样有明确的"列表"，因为：
1. **证据条目数量庞大**：可能有数千个证据条目
2. **证据条目来源多样**：可以从主诉、疾病、诊断学书籍等多个来源提取
3. **证据条目需要去重**：同一个证据可能被多个疾病引用

因此，我们需要一个**证据条目清单**来：
- 帮助内容组知道需要填充哪些证据条目
- 避免重复填充相同的证据条目
- 确保证据条目的完整性和系统性

## 三、证据条目提取指南

### 3.1 从主诉知识图谱中提取证据条目

**提取来源**：

1. **主诉表2（最小关键字段配置表）**：
   - 每个信息点都可以转化为证据条目
   - 例如："起病时间与过程" → "急性胸痛（<1周）"、"慢性胸痛（≥1周）"
   - 例如："伴随症状" → "胸痛伴大汗"、"胸痛伴气促"
   - 例如："诱因" → "活动诱发胸痛"、"静息时胸痛"

2. **主诉表8（关键差异点配置表）**：
   - 每个差异点都可以转化为证据条目
   - 例如："单侧 vs 双侧" → "单侧肿胀"、"双侧肿胀"
   - 例如："急性 vs 慢性" → "急性胸痛"、"慢性胸痛"

3. **主诉表9（检查/检验建议与结果解释）**：
   - 每个检查项目及其结果都可以转化为证据条目
   - 例如："心电图" → "心电图ST段抬高"、"心电图ST段压低"、"心电图正常"

**提取步骤**：

1. **打开主诉知识图谱**，找到要提取的主诉
2. **查看主诉表2**，列出所有信息点
3. **查看主诉表8**，列出所有差异点
4. **查看主诉表9**，列出所有检查项目
5. **将每个信息点/差异点/检查结果转化为证据条目**，填写到"按主诉组织的证据条目清单"中

**示例**：

从"胸痛"主诉中提取证据条目：
- 主诉表2-起病时间与过程 → "急性胸痛（<1周）"、"慢性胸痛（≥1周）"
- 主诉表2-伴随症状 → "胸痛伴大汗"、"胸痛伴气促"、"胸痛伴恶心呕吐"
- 主诉表2-诱因 → "活动诱发胸痛"、"静息时胸痛"
- 主诉表8-差异点 → "单侧胸痛"、"双侧胸痛"（如果适用）
- 主诉表9-检查项目 → "心电图ST段抬高"、"心电图ST段压低"、"心电图正常"

### 3.2 从疾病知识图谱中提取证据条目

**提取来源**：

1. **疾病知识图谱-关键支持证据条目ID列表**：
   - 直接列出该疾病的支持证据
   - 例如："E_单侧肿胀；E_久坐久卧；E_疼痛紧绷"

2. **疾病知识图谱-关键反对证据条目ID列表**：
   - 直接列出该疾病的反对证据
   - 例如："E_双侧对称性水肿；E_明确红热痛"

3. **疾病知识图谱-必须补齐的关键信息条目ID列表**：
   - 列出该疾病必须获取的证据
   - 例如："E_起病速度；E_近期手术卧床；E_是否气促胸痛"

4. **疾病知识图谱-典型表现模式**：
   - 从典型表现中提取证据条目
   - 例如："单侧下肢肿胀；疼痛/紧绷；近期风险因素" → "单侧下肢肿胀"、"疼痛紧绷"、"近期风险因素"

5. **疾病知识图谱-关键鉴别点**：
   - 从鉴别点中提取证据条目
   - 例如："皮肤红热痛：蜂窝织炎更支持" → "皮肤红热痛"

**提取步骤**：

1. **打开疾病知识图谱**，找到要提取的疾病
2. **查看关键支持证据条目ID列表**，列出所有支持证据
3. **查看关键反对证据条目ID列表**，列出所有反对证据
4. **查看必须补齐的关键信息条目ID列表**，列出所有必须获取的证据
5. **查看典型表现模式**，提取其中的证据条目
6. **查看关键鉴别点**，提取其中的证据条目
7. **将每个证据转化为证据条目**，填写到"按疾病组织的证据条目清单"中

**示例**：

从"深静脉血栓形成"疾病中提取证据条目：
- 关键支持证据条目 → "单侧肿胀"、"久坐久卧"、"疼痛紧绷"
- 关键反对证据条目 → "双侧对称性水肿"、"明确红热痛"
- 必须补齐的关键信息 → "起病速度"、"近期手术卧床"、"是否气促胸痛"
- 典型表现模式 → "单侧下肢肿胀"、"疼痛/紧绷"、"近期风险因素"

### 3.3 从诊断学书籍中提取证据条目

**提取来源**：

1. **诊断学-症状学章节**：
   - 提取常见症状及其组合
   - 例如：从"胸痛"章节中提取"胸痛伴大汗"、"胸痛伴气促"等

2. **诊断学-体征学章节**：
   - 提取常见体征
   - 例如：从"心血管系统体征"章节中提取"皮肤苍白"、"呼吸急促"等

3. **诊断学-辅助检查章节**：
   - 提取常见检查结果
   - 例如：从"心电图"章节中提取"ST段抬高"、"ST段压低"等

4. **诊断学-生命体征章节**：
   - 提取测量值类证据
   - 例如：从"生命体征"章节中提取"体温>38.5℃"、"血压异常"等

**提取步骤**：

1. **打开诊断学书籍**，找到相关章节
2. **阅读章节内容**，识别证据条目
3. **将每个证据转化为证据条目**，填写到"按证据类型组织的证据条目清单"中

## 四、证据条目填充工作流程

### 4.1 推荐工作流程

**方式1（推荐）**：先填主诉和疾病，再提取证据条目

1. **第一步**：填写主诉知识图谱（按主诉列表逐个填充）
2. **第二步**：填写疾病知识图谱（按疾病列表逐个填充）
3. **第三步**：从主诉知识图谱中提取证据条目，填写到"按主诉组织的证据条目清单"
4. **第四步**：从疾病知识图谱中提取证据条目，填写到"按疾病组织的证据条目清单"
5. **第五步**：合并去重，整理到"按证据类型组织的证据条目清单"
6. **第六步**：按证据条目知识图谱模板，逐个填充证据条目的详细信息

**方式2**：先提取证据条目，再填主诉和疾病

1. **第一步**：从诊断学书籍中提取常见证据条目，填写到"按证据类型组织的证据条目清单"
2. **第二步**：填写主诉知识图谱时，引用已提取的证据条目
3. **第三步**：填写疾病知识图谱时，引用已提取的证据条目
4. **第四步**：补充主诉和疾病特有的证据条目

### 4.2 证据条目去重规则

**去重原则**：
- 同一个证据条目，即使被多个主诉或疾病引用，也只填充一次
- 证据条目的唯一标识是"证据编号"（E_XXX）

**去重步骤**：
1. **合并清单**：将"按主诉组织的证据条目清单"和"按疾病组织的证据条目清单"合并
2. **识别重复**：找出证据名称相同或相似的证据条目
3. **合并关联关系**：将重复证据条目的关联主诉和关联疾病合并
4. **保留一个**：只保留一个证据条目，删除其他重复项

**示例**：

"胸痛伴大汗"这个证据条目：
- 在"按主诉组织的证据条目清单"中，关联主诉：CC_001（胸痛）
- 在"按疾病组织的证据条目清单"中，关联疾病：DIS_AMI（急性心肌梗死）、DIS_UA（不稳定型心绞痛）
- 去重后，只保留一个证据条目，关联主诉：CC_001，关联疾病：DIS_AMI;DIS_UA

### 4.3 证据条目填充优先级

**优先级1（高优先级）**：
- 主诉表2中的"必须"等级信息点对应的证据条目
- 主诉表8中的关键差异点对应的证据条目
- 疾病知识图谱中的"关键支持证据条目"和"关键反对证据条目"
- 主诉表9中的高价值检查结果对应的证据条目

**优先级2（中优先级）**：
- 主诉表2中的"重要"等级信息点对应的证据条目
- 疾病知识图谱中的"必须补齐的关键信息条目"
- 主诉表9中的一般检查结果对应的证据条目

**优先级3（低优先级）**：
- 其他辅助性证据条目
- 罕见疾病的证据条目
