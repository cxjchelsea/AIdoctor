|------|------|
| **配置文件名称** | `chief_complaint_key_fields.yaml` |
| **文件位置** | `诊断引擎服务/数据/主诉配置/` |
| **对应表** | 主诉表2 - 最小关键字段配置表 |
| **使用位置** | Step 1识别问题、Step 4采集关键证据 |
| **调用服务** | `diagnosis-engine-service`<br>`clinical-parsing-service` |
| **使用方式** | 1. **生成问诊问题**：根据主诉ID加载关键字段配置，生成标准问诊问题<br>2. **字段优先级判断**：根据`required_level`（必须/重要/可选）判断字段优先级<br>3. **答案格式验证**：根据`answer_format`验证用户回答格式<br>4. **缺失处理**：根据`missing_action`处理缺失字段（必须补齐/可继续但降级/命中走兜底）<br>5. **调用示例**：`load_chief_complaint_key_fields(chief_complaint_id="CC_CHEST_PAIN")` |
