# 多源知识融合 - 设计思路

## 问题清单

在多源知识融合过程中，我们可能遇到以下**7个核心问题**：

#### 问题1：权威性对比问题
**问题描述**：如何判断哪个来源更权威？

**问题场景**：
- 来源A是国家级指南，来源B是权威教材，来源C是专业教材
- 当它们对同一疾病有不同描述时，应该相信哪个？

---

#### 问题2：流程完整性问题
**问题描述**：不同书籍的流程步骤不能简单拼接，融合后可能破坏流程的完整性

**问题场景**：
- 来源A的诊断流程：步骤1→步骤2→步骤3（完整流程）
- 来源B的诊断流程：步骤1'→步骤2'→步骤3'（完整流程）
- 不能将A的步骤1和B的步骤2'拼接，因为逻辑不连贯

---

#### 问题3：形式差异问题
**问题描述**：不同书籍的表述形式不同，能否融合？

**问题场景**：
- 来源A：以列表形式描述症状
- 来源B：以段落形式描述症状
- 需要判断内容是否相同、互补，还是冲突

---

#### 问题4：医学专业性问题
**问题描述**：需要医学专业知识来判断融合的合理性

**问题场景**：
- 某些融合决策需要医学专业知识才能判断
- 自动化处理可能无法准确判断医学逻辑

---

#### 问题5：字段缺失问题
**问题描述**：不同来源的字段缺失情况不同，如何确保融合后知识完整？

**问题场景**：
- 来源A：有"诊断标准"、"治疗原则"，缺失"流行病学"
- 来源B：缺失"诊断标准"，有"治疗原则"、"流行病学"
- 如何融合才能保证知识完整？

---

#### 问题6：归纳总结问题
**问题描述**：有些知识可能不直接显示在书籍中，我们是否能够相信AI的总结归纳，以及不同来源对同一内容的归纳可能不同，如何保证融合后的一致性？

**问题场景**：
- 来源A：将分散的症状归纳为"胸痛、胸闷、气短"
- 来源B：将分散的症状归纳为"胸痛、胸闷、气短、心悸"
- 哪个归纳更准确？是否遗漏了关键信息？

---

#### 问题7：模板外内容问题
**问题描述**：书籍中的重要信息可能不在模板中，如何避免遗漏？

**问题场景**：
- 书籍中提到"孕妇需要特殊处理"，但模板中没有"特殊人群注意事项"字段
- 如何确保这些重要信息不被遗漏？

---

## 解决方案

### 2.1 解决方案总览

针对上述7个核心问题，我们设计了**七阶段融合架构**，每个阶段解决特定问题：

```
单书提取结果（多本书）
    ↓
【阶段一】知识对齐与标准化 → 解决：形式差异问题、字段缺失问题
    ↓
【阶段二】权威性评估 → 解决：权威性对比问题
    ↓
【阶段三】冲突检测与分类 → 识别所有问题
    ↓
【阶段四】融合策略选择 → 根据问题类型选择策略
    ↓
【阶段五】融合执行 → 执行融合操作
    ↓
【阶段六】完整性验证 → 验证融合结果
    ↓
【阶段七】医学专业审核 → 解决：医学专业性问题、归纳总结问题、模板外内容问题
    ↓
融合后的知识库
```

---

### 2.2 问题1：权威性对比问题 - 解决方案

#### 2.2.1 解决方案：基于规则的权威性评估体系

**核心思路**：不使用数值评分，而是基于医学实践中的优先级规则和决策树来判断权威性。

#### 2.2.2 优先级层次（从高到低）

1. **第一优先级：国家级指南**
   - 国家卫健委发布的指南
   - 中华医学会发布的指南
   - 中华医学会各专科分会发布的指南

2. **第二优先级：国际指南**
   - WHO指南
   - 国际权威学会指南（如ACC/AHA、ESC、ASCO等）

3. **第三优先级：权威教材**
   - 人民卫生出版社教材（如《内科学》第9版）
   - 高等教育出版社教材

4. **第四优先级：专业教材**
   - 其他出版社的医学教材
   - 专科教材

5. **第五优先级：专家共识**
   - 专家共识文件
   - 学会共识声明

6. **第六优先级：学术论文**
   - 高质量期刊论文（影响因子>5）
   - 系统评价、Meta分析

7. **第七优先级：其他来源**

#### 2.2.3 权威性比较规则

**规则1：优先级层次比较**
- 不同优先级层次，优先级高的更权威
- 例如：国家级指南（第一优先级）比权威教材（第三优先级）更权威

**规则2：同优先级细化判断**
- **指南类**：时间差异≥3年，新版本优先；否则需要专家判断
- **教材类**：最新版本优先；否则需要专家判断
- **其他类**：需要专家判断

#### 2.2.4 字段级权威性要求

不同字段对权威性的要求不同：

| 字段类型 | 权威性要求 | 说明 |
|---------|-----------|------|
| 诊断标准 | 必须来自第一或第二优先级 | 必须来自指南 |
| 治疗原则 | 必须来自第一或第二优先级 | 必须来自指南 |
| 药物剂量 | 必须来自第一优先级，且为最新版本 | 必须来自最新国家级指南 |
| 病因机制 | 可接受第一到第四优先级 | 可接受指南和教材 |
| 临床表现 | 可接受第一到第四优先级 | 可接受指南和教材 |
| 概述描述 | 可接受所有优先级 | 可接受多种来源 |

### 2.3 问题2：流程完整性问题 - 解决方案

#### 2.3.1 解决方案：流程选择策略

**核心思路**：不能简单拼接不同来源的流程步骤，必须选择完整的流程。

#### 2.3.2 处理策略

**策略1：流程选择**
- 选择最权威、最完整的流程
- 其他流程作为备选方案
- 保留所有流程的完整信息

**策略2：分段融合（如果可行）**
- 将流程分段（如：初步诊断段、鉴别诊断段、确诊段）
- 每段选择最优来源
- 确保段内逻辑连贯

**策略3：人工审核**
- 如果流程不能自动融合，必须人工审核
- 由医学专家决定融合方案

#### 2.3.3 流程完整性检查

**检查项**：
- 流程是否有明确的开始和结束
- 流程步骤之间是否有逻辑连贯性
- 流程步骤是否有依赖关系
- 流程是否完整（不缺少关键步骤）

---

### 2.4 问题3：形式差异问题 - 解决方案

#### 2.4.1 解决方案：内容关系判断与形式统一

**核心思路**：判断内容关系（相同/互补/冲突），然后统一形式。

#### 2.4.2 处理流程

```
检测形式差异
    ↓
判断内容关系
    ├─ 内容相同 → 选择更权威的来源，统一形式
    ├─ 内容互补 → 合并内容，统一形式
    └─ 内容冲突 → 按值冲突处理
    ↓
统一形式
    - 列表形式 → 统一为列表
    - 段落形式 → 统一为段落
    - 表格形式 → 统一为表格
```

#### 2.4.3 内容关系判断方法

**核心原则**：不使用语义相似度等算法，而是基于**直接对比**和**人工判断**。

**方法1：直接文本对比**
- 直接对比两个来源的文本内容
- 如果文本完全相同或高度相似（肉眼可见），判断为内容相同
- 如果文本部分重叠，判断为内容互补
- 如果文本完全不同，判断为内容冲突

**方法2：结构化字段对比**
- 如果内容是结构化的（如列表、表格），逐项对比
- 列表项完全相同：内容相同
- 列表项部分相同：内容互补
- 列表项完全不同：内容冲突

**方法3：人工判断**
- 对于无法自动判断的情况，必须人工判断
- 由医学专家对比两个来源的内容，判断关系
- 记录判断结果和理由

**判断标准**：
- **内容相同**：两个来源的内容在医学意义上相同（即使表述略有不同）
- **内容互补**：两个来源的内容可以相互补充，不冲突
- **内容冲突**：两个来源的内容存在矛盾或冲突

### 2.5 问题4：医学专业性问题 - 解决方案

#### 2.5.1 解决方案：人工审核机制

**核心思路**：关键融合决策必须由医学专家审核。

#### 2.5.2 必须人工审核的情况

1. **流程完整性冲突**（不能自动融合）
2. **高严重程度的值冲突**（诊断标准、治疗原则、药物剂量）
3. **逻辑冲突**
4. **优先级层次相同且时间差异<3年的冲突**
5. **必填字段缺失**
6. **归纳结果冲突**
7. **高重要性的模板外内容冲突**

---

### 2.6 问题5：字段缺失问题 - 解决方案

#### 2.6.1 解决方案：字段缺失互补融合

**核心思路**：通过互补融合，使用有该字段的来源填充缺失字段。但必须**保证权威性**和**完整性**。

**关键问题**：
- ⚠️ **权威性保证**：单独使用某个来源的字段，是否还具有足够的权威性？
- ⚠️ **完整性保证**：该来源的字段内容是否完整，是否足以填充缺失字段？

#### 2.6.2 处理流程

```
识别字段缺失情况
    ↓
按字段重要性分类
    ├─ 必填字段缺失 → 必须找到或人工补充
    ├─ 重要字段缺失 → 优先使用有该字段的来源
    └─ 可选字段缺失 → 允许缺失
    ↓
互补融合
    - 如果部分来源有该字段，使用有该字段的来源（优先选择最权威的来源）
    - 如果所有来源都缺失，标记为缺失，记录缺失原因
    ↓
记录字段来源
    - 每个字段都要记录来源
    - 记录字段状态（filled/missing/summarized）
```

#### 2.6.3 字段缺失对齐规则

**规则1：必填字段缺失**
- 如果所有来源都缺失，必须人工补充
- 如果部分来源有，**必须检查权威性要求**：
  - 检查该字段的权威性要求（如诊断标准必须来自指南）
  - 检查有该字段的来源是否满足权威性要求
  - 如果满足，可以使用；如果不满足，必须人工审核或补充

**规则2：重要字段缺失**
- 优先使用有该字段的来源
- **必须检查权威性要求**：
  - 检查该字段的权威性要求
  - 检查有该字段的来源是否满足权威性要求
  - 如果满足，可以使用；如果不满足，标记为需要人工审核
- 如果所有来源都缺失，标记为缺失，记录缺失原因

**规则3：可选字段缺失**
- 允许缺失
- 如果部分来源有，使用有该字段的来源（优先选择最权威的来源）

#### 2.6.4 权威性保证机制

**问题**：单独使用某个来源的字段，是否还具有足够的权威性？

**解决方案**：

1. **字段级权威性检查**
   - 每个字段都有权威性要求（见问题1的解决方案）
   - 在使用某个来源的字段前，必须检查该来源是否满足该字段的权威性要求
   - 例如：诊断标准字段要求必须来自指南（第一或第二优先级），如果某个来源是教材（第三优先级），即使它有该字段，也不能直接使用

2. **多来源验证**
   - 如果只有一个来源有该字段，且该来源满足权威性要求，可以使用
   - 如果有多个来源有该字段，优先选择最权威的来源
   - 如果最权威的来源不满足字段的权威性要求，必须人工审核

3. **完整性检查**
   - 检查该来源的字段内容是否完整
   - 如果内容不完整，标记为需要补充
   - 如果内容完整，可以使用

4. **人工审核机制**
   - 对于必填字段和重要字段，如果使用单一来源，必须人工审核
   - 人工审核确认该来源的字段内容是否完整、准确、权威

#### 2.6.5 权威性保证示例

**场景1：权威性满足**
- 字段：诊断标准（要求：必须来自指南）
- 来源A：国家级指南（第一优先级），有该字段
- 来源B：权威教材（第三优先级），缺失该字段
- **处理**：使用来源A的字段，因为来源A满足权威性要求

**场景2：权威性不满足**
- 字段：诊断标准（要求：必须来自指南）
- 来源A：权威教材（第三优先级），有该字段
- 来源B：专业教材（第四优先级），缺失该字段
- **处理**：不能直接使用来源A的字段，因为来源A不满足权威性要求。必须人工审核或寻找其他来源。

**场景3：多来源验证**
- 字段：临床表现（要求：可接受指南和教材）
- 来源A：国家级指南（第一优先级），有该字段
- 来源B：权威教材（第三优先级），有该字段
- **处理**：优先使用来源A的字段（最权威），来源B作为补充参考

### 2.7 问题6：归纳总结问题 - 解决方案

#### 2.7.1 解决方案：归纳结果审核与对比

**核心思路**：不能完全相信AI的归纳，必须人工审核归纳结果。**如果找不到原始段落，必须人工审核归纳的合理性**。

**关键问题**：
- ⚠️ **找不到原始段落**：归纳就是因为找不到原始段落才用归纳，这种情况怎么办？
- ⚠️ **归纳的可信度**：如何判断归纳是否准确、完整？

#### 2.7.2 处理流程

```
检测归纳结果冲突
    ↓
检查是否有原始段落
    ├─ 有原始段落 → 对比原始段落
    │   - 提取两个来源的原始段落
    │   - 对比段落内容
    │   - 判断哪个归纳更完整、更准确
    └─ 没有原始段落 → 直接进入人工审核
        - 无法通过原始段落验证
        - 必须人工审核归纳的合理性
    ↓
判断归纳关系
    ├─ 归纳结果互补 → 合并归纳结果（需人工确认）
    ├─ 归纳结果相同 → 选择更权威的来源（需人工确认）
    └─ 归纳结果冲突 → 人工审核
    ↓
人工审核（必须）
    - 检查归纳是否准确
    - 检查是否遗漏关键信息
    - 检查归纳是否符合医学逻辑
    - 修正不准确的归纳
    - 如果找不到原始段落，评估归纳的可信度
```

#### 2.7.3 归纳结果对比方法

**方法1：原始段落对比（如果有原始段落）**
- 提取两个来源的原始段落
- 直接对比段落内容，判断哪个归纳更完整
- 如果段落内容相同，但归纳不同，说明归纳有问题
- **注意**：如果找不到原始段落，跳过此方法

**方法2：归纳结果直接对比（如果没有原始段落）**
- 直接对比两个来源的归纳结果
- 检查归纳结果是否包含相同的关键信息
- 检查归纳结果是否有遗漏或错误
- **必须人工审核**：无法通过原始段落验证，必须人工判断归纳的合理性

**方法3：医学逻辑检查**
- 检查归纳结果是否符合医学逻辑
- 检查归纳结果是否与已知医学知识一致
- 如果归纳结果不符合医学逻辑，标记为需要修正

**方法4：来源权威性检查**
- 检查归纳结果的来源权威性
- 优先使用权威来源的归纳结果
- 但即使来源权威，也必须人工审核归纳的准确性

#### 2.7.4 归纳结果融合规则

**规则1：有原始段落的情况**
- 如果两个来源都有原始段落，对比原始段落
- 如果原始段落内容相同，但归纳不同，说明归纳有问题，必须人工审核
- 如果原始段落内容不同，但归纳结果互补，可以合并归纳结果（需人工确认）

**规则2：没有原始段落的情况**
- ⚠️ **必须人工审核**：无法通过原始段落验证，必须人工判断归纳的合理性
- 由医学专家评估归纳结果是否符合医学逻辑
- 由医学专家判断哪个归纳更准确、更完整
- 如果无法判断，标记为需要更多信息或拒绝使用

**规则3：互补融合**
- 如果归纳结果互补（来源A有信息1、2、3，来源B有信息1、2、3、4），可以合并归纳结果
- **但必须人工确认**：合并后的归纳结果是否完整、准确

**规则4：权威优先**
- 如果归纳结果相同，优先选择更权威的来源
- **但必须人工确认**：即使来源权威，也必须确认归纳的准确性

**规则5：归纳结果冲突**
- 如果归纳结果冲突，必须人工审核
- 由医学专家判断哪个归纳更准确
- 如果无法判断，标记为需要更多信息或拒绝使用

#### 2.7.5 找不到原始段落的处理策略

**问题**：归纳就是因为找不到原始段落才用归纳，这种情况怎么办？

**解决方案**：

1. **必须人工审核**
   - 如果找不到原始段落，无法通过原始段落验证归纳的准确性
   - 必须由医学专家人工审核归纳的合理性
   - 医学专家需要评估归纳结果是否符合医学逻辑

2. **评估归纳的可信度**
   - 检查归纳结果的来源权威性
   - 检查归纳结果是否符合已知医学知识
   - 检查归纳结果是否完整（是否遗漏关键信息）
   - 如果可信度低，标记为需要更多信息或拒绝使用

3. **多来源验证**
   - 如果多个来源都有归纳结果，对比归纳结果
   - 如果归纳结果一致，可信度较高
   - 如果归纳结果不一致，必须人工审核

4. **拒绝使用策略**
   - 如果无法验证归纳的准确性，且可信度低，可以拒绝使用该归纳结果
   - 标记为需要更多信息或需要人工补充

**示例**：

**场景1：找不到原始段落，但归纳结果一致**
- 来源A：归纳为"胸痛、胸闷、气短"
- 来源B：归纳为"胸痛、胸闷、气短"
- 两个来源的归纳结果一致，但都找不到原始段落
- **处理**：归纳结果一致，可信度较高，但仍需人工审核确认

**场景2：找不到原始段落，且归纳结果不一致**
- 来源A：归纳为"胸痛、胸闷、气短"
- 来源B：归纳为"胸痛、胸闷、气短、心悸"
- 两个来源的归纳结果不一致，且都找不到原始段落
- **处理**：必须人工审核，由医学专家判断哪个归纳更准确，或是否需要合并

**场景3：找不到原始段落，且可信度低**
- 来源A：归纳为"胸痛、胸闷、气短"
- 但该归纳结果不符合已知医学知识，或来源权威性低
- **处理**：标记为需要更多信息或拒绝使用，需要人工补充

### 2.8 问题7：模板外内容问题 - 解决方案

#### 2.8.1 解决方案：模板外内容识别与处理

**核心思路**：识别模板外的重要内容，临时存储，定期分析，优化模板。

#### 2.8.2 处理流程

```
识别模板外内容
    ↓
判断内容重要性
    ├─ 高重要性 → 必须记录，建议模板优化
    ├─ 中重要性 → 记录，可选模板优化
    └─ 低重要性 → 记录，暂不优化模板
    ↓
临时存储
    - 存储到扩展字段
    - 标注来源和重要性
    ↓
定期分析
    - 统计出现频率
    - 分析内容模式
    ↓
提出优化建议
    - 新增字段建议
    - 字段结构调整
    ↓
专家评审
    - 医学专家评审
    - 决定是否优化模板
```

#### 2.8.3 模板外内容识别方法

**方法1：AI辅助识别**
- 在提取过程中，AI识别出重要但模板中没有的信息
- 标记为"模板外重要内容"

**方法2：人工审核发现**
- 审核人员在审核过程中发现
- 标记为"模板外内容"

**方法3：批量分析**
- 对已提取的数据进行批量分析
- 识别常见但模板中没有的内容

#### 2.8.4 重要性判断标准

**高重要性**：
- 影响诊断/治疗的关键信息
- 特殊人群注意事项
- 禁忌症和不良反应
- 紧急处理措施

**中重要性**：
- 重要的补充信息
- 临床经验总结
- 特殊情况处理

**低重要性**：
- 一般性信息
- 背景知识
- 历史信息

#### 2.8.5 模板优化流程

**步骤1：收集模板外内容**
- 统计出现频率
- 分析内容类型
- 识别内容模式

**步骤2：提出优化建议**
- 新增字段建议
- 字段结构调整建议

**步骤3：专家评审**
- 医学专家评审
- 技术团队评估

**步骤4：模板版本更新**
- 创建新版本模板
- 迁移历史数据
