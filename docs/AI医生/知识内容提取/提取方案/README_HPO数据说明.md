# HPO（人类表型本体）数据说明文档

## 📋 什么是HPO？

HPO（Human Phenotype Ontology，人类表型本体）是一个标准化的医学词汇表，用于描述人类疾病相关的异常表型（症状、体征等）。

**简单理解**：就像字典一样，HPO为各种症状、体征提供了统一的编码和名称，确保不同的医生、不同的系统在描述同一个症状时使用相同的术语。

## 📁 文件说明

运行数据提取后，会生成以下文件：

1. **hpo_data.json** - 完整的JSON格式数据（程序使用）
2. **hpo_data.csv** - 完整的CSV表格（可用Excel打开查看所有数据）
3. **hpo_data_示例_前1000条.csv** - 前1000条示例数据（方便快速查看）
4. **hpo_data_报告.html** - HTML格式的示例报告（在浏览器中打开查看）

## 📊 CSV文件字段说明

CSV文件包含以下列，每一行代表一个HPO术语：

| 列名 | 说明 | 示例 |
|------|------|------|
| **HPO编码** | 唯一的标识符，格式为HP:后跟7位数字 | HP:0000107 |
| **标准名称（英文）** | 该术语的官方英文名称 | Renal cyst |
| **定义** | 对术语的详细定义说明 | A fluid-filled sac in the kidney... |
| **注释** | 补充说明信息 | Renal cysts can be... |
| **精确同义词** | 与标准名称完全等价的同义词（多个用分号分隔） | Kidney cyst; Renal cystic lesion |
| **相关同义词** | 相关但不完全等价的同义词（多个用分号分隔） | Cystic kidney disease |
| **父类HPO编码** | 上级分类的HPO编码（多个用分号分隔） | HP:0012210 |
| **子类HPO编码** | 下级分类的HPO编码（多个用分号分隔） | HP:0000080; HP:0000081 |
| **是否为叶子节点** | 是否是最具体的分类（没有下级分类） | 是/否 |
| **替代ID** | 历史版本或替代的编码（多个用分号分隔） | HP:0004715 |
| **是否已废弃** | 该术语是否已经不再使用 | 是/否 |
| **被替换为** | 如果已废弃，新的替代术语编码 | HP:XXXXXXX |
| **创建日期** | 术语创建的时间 | 2008-02-27T02:20:00Z |
| **外部引用** | 关联的其他医学术语编码（如UMLS、SNOMED等） | UMLS:C0444868 |

## 🔍 实际应用示例

### 示例1：查找症状的同义词

假设医生在病历中写的是"多囊肾"（Multicystic kidney），系统可以通过HPO数据找到：
- **标准名称**：Multicystic kidney dysplasia
- **精确同义词**：Multicystic dysplastic kidney, Multicystic renal dysplasia, Multicystic kidneys
- **HPO编码**：HP:0000003

这样即使医生用不同的词汇描述，系统都能识别为同一个HPO术语。

### 示例2：理解症状的层次关系

HPO术语之间有层级关系，就像文件夹结构：

```
HP:0000001 (All - 所有)
  └─ HP:0012210 (Abnormal renal morphology - 异常肾脏形态)
      └─ HP:0000107 (Renal cyst - 肾囊肿)
          └─ HP:0000003 (Multicystic kidney dysplasia - 多囊肾发育不良)
```

通过查看"父类HPO编码"和"子类HPO编码"列，可以了解：
- 这个症状属于哪个大类
- 有哪些更具体的细分类型

### 示例3：识别已废弃的术语

如果某个HPO术语已经废弃，"是否已废弃"列会显示"是"，"被替换为"列会显示新的术语编码。这样可以确保使用最新的医学术语标准。

## 💡 如何使用这些数据

### 方式1：使用Excel查看（推荐）

1. 双击打开 `hpo_data.csv` 文件
2. 使用Excel的筛选功能查找特定的症状
3. 可以按"标准名称"列搜索，或按"精确同义词"列搜索
4. 使用排序功能可以按HPO编码排序

### 方式2：查看HTML报告

1. 双击打开 `hpo_data_报告.html` 文件（会在浏览器中打开）
2. 可以查看前100个示例术语的详细信息
3. 界面美观，适合展示和演示

### 方式3：程序中使用JSON

如果您是技术人员，可以在程序中直接使用 `hpo_data.json` 文件。
