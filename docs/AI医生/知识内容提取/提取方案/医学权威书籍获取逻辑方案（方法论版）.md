# 医学权威书籍获取逻辑方案（方法论版）

> **目标**：
> 针对任意一种疾病，系统性、可复用地获取**权威、全面、广而深**的医学书籍与资料，避免碎片化、科普化和主观筛选偏差，为医学决策、知识沉淀和 AI 应用提供可靠知识源。

## 一、核心思想

**不“找书”，而是“从医学体系反推书籍”**
——先锁定医学共识体系，再回溯其权威载体。

## 二、整体逻辑框架（总览）

```
疾病 → 医学专科 → 权威教材体系 → 疾病专项专著 → 临床指南 → 中文本地化补充
```

这是一个**自上而下、逐层收敛可信度**的过程。

## 三、六步逻辑方案（完善版）

### Step 1｜疾病医学归属判定（第一性约束）

**目的**：避免从一开始就跑偏

- 明确疾病的**核心医学专科**
- 识别是否涉及 **多学科（MDT）**

示例：

- 糖尿病 → 内分泌科（主）＋心血管（并发）
- 阿尔茨海默病 → 神经内科＋精神医学
- 肿瘤 → 肿瘤学＋外科＋影像＋病理

### Step 2｜锁定“专科级权威教材”（知识母本）

**原则**：

> 所有疾病知识，首先必须能在**该专科的权威教材中被定位**

做法：

- 不找疾病书
- 先找 **该专科全球通用教材**
- 通过目录（TOC）定位疾病章节

特点：

- 体系完整
- 内容稳定
- 经多代医学教育验证

### Step 3｜疾病专项专著（纵深补充）

**目的**：在“总地图”基础上做深挖

筛选原则：

- 专病专书（非泛健康）
- 多版次（≥3 版优先）
- 主编来自权威医学中心
- 医学出版社出版

### Step 4｜循证指南与学会共识（决策边界）

**定位**：
书籍 ≠ 决策标准，**指南才是“能不能这么做”的答案**

必查：

- 国际指南（WHO / 国际学会）
- 国家级或地区级指南
- 最新共识声明

用途：

- 诊断标准
- 治疗路径
- 风险分层
- 禁忌与边界

### Step 5｜中文资料的角色重定义（不是主源）

**原则**：

- 中文资料 ≠ 权威源
- 中文资料 = 本地化补充

使用场景：

- 医疗体系差异
- 药品可及性
- 本土指南解读

禁止场景：

- 作为唯一依据
- 作为规则生成母本

### Step 6｜质量校验与交叉验证（方法论闭环）

最终必须满足：

- 同一结论 ≥ 2 个不同体系来源支持
  （教材 / 专著 / 指南）
- 不同国家指南结论无重大冲突
- 教材与指南在核心结论上不矛盾

这一版可以直接作为**正式方法论**使用，逻辑收敛、结论明确，不会被反问击穿。

# 医学权威书籍获取与复用方案（最终版）

## 一、方案目标（先把目标说清楚）

> 建立一套**稳定、可复用、可审计**的医学权威书籍获取与使用方案，
> 用于系统性填充疾病知识图谱，确保知识来源**权威、全面、长期有效**。

------

## 二、核心原则（一句话总纲）

> **不是“为每一种疾病找一套书”，
> 而是“为每一个医学专科建立权威书籍母本，再在母本中定位疾病”。**

这是整个方案的核心思想。

------

## 三、总体结构（先看全局）

```
医学专科
  ↓
专科权威教材（母本）
  ↓
疾病章节定位（默认）
  ↓
必要时补充疾病专著（例外）
  ↓
指南用于规则与决策边界
```

------

## 四、具体执行方案（标准流程）

### Step 1｜按医学专科建立“权威书籍母本库”

**执行规则：**

- 以医学专科为单位，而不是以疾病为单位
- 每个专科只做 **1 次完整找书流程**

**每个专科固定配置：**

- 1–2 本国际公认的专科权威教材
- 覆盖该专科下所有核心疾病

**结果产出：**

- 一个“专科 → 权威教材”的稳定映射关系

------

### Step 2｜单个疾病只做“章节定位”，不重新找书

**执行规则：**

- 不再重复走“找书流程”
- 只在已确定的专科教材中：
  - 定位该疾病的章节
  - 提取结构化医学共识内容

**这一步解决：**

- 疾病定义
- 边界与分类
- 典型/非典型表现
- 鉴别诊断
- 机制与演变

------

### Step 3｜仅在满足条件时，才补充“疾病专项专著”

**补书是例外，而不是默认。**

**只有当疾病满足以下任一条件，才补专著：**

- 存在大量亚型 / 表型
- 诊疗路径差异显著
- 属于高风险或 must-not-miss 疾病
- 涉及长期管理或生物靶向治疗
- 是系统中的重点疾病（高频 / 高风险）

否则：

- **不额外找书**
- **专科教材 + 指南已足够**

------

### Step 4｜指南不替代书，但用于“规则与边界”

**清晰分工：**

- 📘 教材 / 专著 → 填充“疾病是什么”
- 📋 指南 → 定义“能不能这么做”

**指南负责的内容：**

- 诊断成立/排除标准
- 治疗分级与路径
- 风险分层
- 升级就医与红旗条件
