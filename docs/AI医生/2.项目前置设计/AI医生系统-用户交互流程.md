# AI医生系统 - 用户交互流程

---

## 一、开始使用

### 1.1 首次进入

**用户看到**：
- 对话界面（左侧：对话区域，右侧：信息面板）
- 系统欢迎消息："您好，我是智能诊断助手。请描述您的问题或需求，我会根据您提供的信息为您提供帮助。"
- 信息面板按钮："开始新诊断"、"我的病例"、"健康档案"

**用户操作**：
- 在输入框中输入问题或需求（文字、图片、语音）

**用户看到**：
- 系统立即响应，开始对话
- 系统在后台完成入口判定（P0模块）并**无感**给出引导（不展示“正在评估/正在判定”等页面）
- 信息面板会显示本次会话的**工作态标签**（健康管理态/临床诊疗态）与**风险等级（L1-L4）**
- 如果需求不明确，系统可能询问一次方向澄清："请确认一下，您主要是想进行健康筛查/体检规划，还是想咨询症状问题？"
- 如果命中危险信号（红旗信号），系统会立即提示并**退出线上流程**："检测到危险信号，建议您立即就医。"

## 二、健康筛查流程（无症状用户）

### 2.1 需求分类

**用户看到**：
- 系统识别用户需求类型（筛查建议/目标管理/计划性需求）

**用户操作**：
- 确认需求类型（或系统自动识别）

### 2.2 收集健康画像

**用户看到**：
- 系统询问基本信息：
  - "请问您的年龄和性别是？"
  - "是否有既往病史？"
  - "是否有家族史？"
  - "生活习惯如何？（吸烟、饮酒、运动等）"
- 信息完整度进度条（显示收集进度）

**用户操作**：
- 回答系统提问
- 可以跳过部分非必填项（系统会提示哪些是必填项）

### 2.3 执行分支

**根据需求类型，用户看到不同的内容**：

#### 筛查建议分支

**用户看到**：
- 系统询问影响筛查决策的关键信息
- 筛查建议清单：
  - **推荐做的筛查**：项目名称、频率、时机、原因
  - **不建议做的筛查**：项目名称、不推荐理由、替代建议

**用户操作**：
- 查看筛查建议
- 可以询问为什么推荐/不推荐某项筛查

#### 健康目标管理分支

**用户看到**：
- 系统询问："您想要改善的具体目标是什么？（减脂/睡眠/运动/精力等）"
- 系统询问："当前状态如何？"、"可用的时间、精力、经济资源？"、"期望的改善周期？"
- 可执行行动计划：
  - 行动步骤
  - 追踪指标（2-3个关键指标）
  - 复盘节点

**用户操作**：
- 回答系统提问
- 确认行动计划

#### 计划性健康需求分支

**用户看到**：
- 系统询问："具体的场景任务是什么？（备孕/疫苗/差旅/材料等）"
- 系统询问："任务的时间节点？"、"是否有禁忌症或特殊情况？"
- 检查清单和时间表：
  - 需要完成的检查项目
  - 检查的时间安排
  - 注意事项

**用户操作**：
- 回答系统提问
- 查看检查清单和时间表

### 2.4 统一结果页

**用户看到**：
- **一句话总结**：总结本次咨询的核心建议
- **现在建议做的事（清单）**：明确建议用户执行的事项
- **暂时不建议做的事（清单）**：明确不建议的事项及理由
- **下一次复查/更新时间点**：明确的随访时间
- **退出条件提示**：出现不适/危险信号→线下评估

**用户操作**：
- 查看结果
- 可以保存结果
- 可以分享给家人或医生

### 2.5 随访设置

**用户看到**：
- 随访计划：
  - 随访日期
  - 提醒内容
  - 复评触发条件

**用户操作**：
- 确认随访计划
- 可以修改提醒时间

## 三、症状诊断流程（有症状用户）

### 3.1 问诊阶段

**用户看到**：
- 系统追问关键信息：
  - "症状持续多久了？"
  - "症状是突然出现的还是慢慢加重的？"
  - "症状的严重程度如何？（0-10分）"
  - "是否有伴随症状？"
  - "是否有既往病史？"
- 信息完整度进度条（显示收集进度）
- 5步AI循证诊断流程进度指示器（显示当前步骤）

**用户操作**：
- 回答系统提问
- 可以点击选项按钮快速选择
- 可以上传检查报告或图片
- 可以补充体征数据（血压、心率等）

### 3.2 分析阶段

**用户看到**：
- 系统显示分析进度："正在分析可能的原因..."（此处为临床诊疗态的分析阶段，区别于入口阶段的“无感判定”）
- 5步流程进度指示器（显示当前步骤）

**用户操作**：
- 等待系统分析（通常几秒钟）

### 3.3 诊断结果

**用户看到**（在对话中显示诊断结果卡片）：
- **结论**：可确证/不可确证标识
- **三层分层结构**：
  - 【首要假设】（1个）：最可能的诊断
  - 【主要备选诊断】（1-2个）：其他可能的诊断
  - 【必须排除的高危诊断】（0-1个）：必须排除的高危诊断
- **必须排除项状态**：已排除/未排除/需线下排除
- **关键依据**：至少三条证据
- **行动与随访**：立即行动、复评时间窗、升级触发条件

**用户操作**：
- 查看诊断结果
- 点击"查看详情"查看完整结果
- 可以保存报告
- 可以分享给家人或医生

### 3.4 诊断结果详情（点击"查看详情"后）

**用户看到**：
- **结论**：
  - 可确证/不可确证标识
  - 诊断时间
- **三层分层结构**：
  - 【首要假设】（1个）：疾病名称、可能性、支持证据、反对证据
  - 【主要备选诊断】（1-2个）：疾病名称、可能性、依据
  - 【必须排除的高危诊断】（0-1个）：疾病名称、排除状态、排除理由
- **必须排除项状态**：
  - 已排除：哪些高危诊断已排除，排除理由
  - 未排除：哪些高危诊断未排除，未排除原因
  - 需线下排除：哪些高危诊断需要线下检查才能排除
- **关键依据**：
  - 阳性证据（支持最可能方向，至少三条）
  - 关键阴性证据（排除其他方向）
  - 检查结果（如有）
- **行动与随访**：
  - 立即行动：就医建议、检查建议、治疗方向、紧急情况处理建议
  - 复评时间窗：默认复评时间、提前复评条件、延迟复评条件
  - 升级触发条件：出现哪些情况必须立即就医
- **建议检查**：
  - 优先检查（高优先级）：检查项目、目的、优先级、说明
  - 可选检查（中低优先级）：检查项目、目的、优先级、说明
- **就医建议**：
  - 建议科室
  - 就医时机
  - 就医准备：需带资料、建议询问医生的问题
  - 就医摘要（SBAR格式，可复制）

**用户操作**：
- 查看完整诊断结果
- 保存报告
- 分享给家人或医生
- 复制就医摘要
- 可以重新诊断

## 四、特殊场景

### 4.1 危险信号场景

**用户看到**：
- 系统立即提示："检测到危险信号，建议您立即就医。"
- 危险信号列表
- 紧急处理建议

**用户操作**：
- 听从建议立即就医
- 可以查看危险信号详情

### 4.2 上传检查报告场景

**用户看到**：
- 上传按钮（在输入区域或快速操作中）
- 上传对话框（支持拖拽上传）
- 上传进度显示
- OCR识别结果：
  - 原始文本
  - 结构化数据（表格形式）
- 自动解读结果（在对话中显示）

**用户操作**：
- 上传检查报告（图片/PDF）
- 确认识别结果（可以修改）
- 查看解读结果

### 4.3 补充体征数据场景

**用户看到**：
- "补充体征数据"按钮（在快速操作中）
- 体征输入对话框：
  - 血压、心率、体温、血氧等
  - 正常值范围提示

**用户操作**：
- 输入体征数据
- 确认提交

### 4.4 随访场景

**用户看到**：
- 系统主动提醒："您感觉如何？"
- 系统提醒："距离上次诊断已经X天了，请告诉我您的症状变化"
- 随访提醒（在信息面板或通知中）

**用户操作**：
- 回答系统提问
- 可以主动发起随访

### 4.5 路径切换场景

**用户看到**：
- 如果用户在健康筛查流程中后续出现症状描述，系统会询问："您刚才提到了症状，是否需要切换到症状诊断流程？"
- 如果用户在症状诊断流程中明确只是想筛查，系统会询问："您主要是想进行健康筛查，是否需要切换到健康筛查流程？"

**用户操作**：
- 确认切换路径
- 或继续当前路径

## 五、常用操作

### 5.1 开始新诊断

**用户操作**：
1. 点击信息面板顶部的"开始新诊断"按钮
2. 系统清空当前对话
3. 显示欢迎消息
4. 用户可以开始新的咨询

### 5.2 查看历史病例

**用户操作**：
1. 点击信息面板顶部的"我的病例"按钮
2. 打开病例列表抽屉
3. 查看历史病例列表
4. 点击"查看结果"查看已完成诊断
5. 点击"继续诊断"继续未完成诊断

### 5.3 查看健康档案

**用户操作**：
1. 点击信息面板顶部的"健康档案"按钮
2. 打开健康档案抽屉
3. 查看健康档案详情
4. 点击"编辑健康档案"修改信息

### 5.4 上传检查报告

**用户操作**：
1. 方式1：在输入区域点击"上传"按钮
2. 方式2：在快速操作中点击"上传检查报告"按钮
3. 选择文件（图片/PDF）或拖拽上传
4. 等待OCR识别完成
5. 确认识别结果
6. 查看自动解读结果

### 5.5 补充体征数据

**用户操作**：
1. 在快速操作中点击"补充体征数据"按钮
2. 打开体征输入对话框
3. 输入体征数据（血压、心率、体温等）
4. 确认提交

### 5.6 查看诊断结果详情

**用户操作**：
1. 诊断完成后，在对话中查看诊断结果卡片
2. 点击"查看详情"按钮
3. 在信息面板或抽屉中查看完整结果
4. 可以保存、分享、复制就医摘要

## 六、用户界面元素

### 6.1 对话区域

**用户看到**：
- 对话消息列表（用户消息、系统消息、追问问题）
- 信息完整度进度条
- 5步AI循证诊断流程进度指示器（症状诊断时显示）
- 输入区域（文本输入、上传按钮、发送按钮）

### 6.2 信息面板

**用户看到**：
- 顶部操作区："开始新诊断"、"我的病例"、"健康档案"按钮
- 信息完整度卡片
- 已收集信息摘要
- 快速操作："上传检查报告"、"补充体征数据"按钮

### 6.3 诊断结果卡片

**用户看到**：
- 结论标识（可确证/不可确证）
- 三层分层结构（首要假设、主要备选、必须排除）
- 关键依据
- 行动与随访建议
- 操作按钮："查看详情"、"保存"、"分享"
