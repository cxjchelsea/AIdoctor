# 报告解读系统 - 知识内容需求

---

## 一、服务说明

**报告解读系统**：独立于AI医生系统的报告解读服务，负责解析各种检查报告（如血常规、肝功能、心电图等），识别异常指标，评估临床意义，并提供解读建议。

---

## 二、知识内容清单

| 序号 | 知识内容名称 | 作用说明 |
|-----|------------|---------|
| **1.1** | **检查项目归一化词表** | **作用**：将不同医院、不同报告格式中使用的检查项目名称统一成标准名称，确保系统能正确识别报告类型。<br>**举例**：不同医院可能用"血常规"、"血象"、"血细胞分析"、"Complete Blood Count"、"CBC"等不同名称，系统都要能识别为"血常规检查"这个标准名称。不同报告格式中可能用"肝功能"、"肝功"、"Liver Function Test"、"LFT"等，系统都要能识别为"肝功能检查"。<br>**内容组需要准备**：整理每个检查项目的标准名称、标准编码、同义名称（包括不同医院、不同地区、不同报告格式的用法），以及各种可能的表达方式（中文、英文、缩写等）。 |
| **1.2** | **指标名称归一化词表** | **作用**：将不同医院、不同报告格式中使用的指标名称统一成标准名称，确保系统能正确识别和提取指标数值。<br>**举例**：不同报告可能用"白细胞"、"白细胞计数"、"WBC"、"White Blood Cell"、"白细胞数"等不同名称，系统都要能识别为"白细胞"这个标准名称。不同报告可能用"血红蛋白"、"Hb"、"HGB"、"Hemoglobin"等，系统都要能识别为"血红蛋白"。<br>**内容组需要准备**：整理每个检查指标的标准名称、标准编码、同义名称（包括不同医院、不同地区、不同报告格式的用法），以及各种可能的表达方式（中文、英文、缩写等），还包括单位映射关系（如"10^9/L"、"×10^9/L"、"10^9/L"等不同单位表达的统一）。 |
| **1.3** | **检查报告模板库** | **作用**：定义不同医院、不同检查类型的报告格式，告诉系统如何从报告中找到各项指标的位置和数值，以及如何解析报告结构。<br>**举例**：对于"血常规"报告，系统需要知道：<br>- 标题关键词："血常规"、"血象"、"CBC"、"Complete Blood Count"等<br>- 指标位置：指标名称可能在数值前、数值后，或单独一行<br>- 数值提取规则："白细胞"可能在报告中用"白细胞"、"WBC"、"White Blood Cell"等关键词表示，数值通常在关键词后面，单位可能是"10^9/L"或"×10^9/L"<br>- 报告结构：可能是表格格式、列表格式、文本格式等<br>**内容组需要准备**：整理常见检查报告（血常规、肝功能、肾功能、心电图、影像学检查等）的格式，包括：标题关键词、报告结构类型、指标位置规则、数值提取规则、单位识别规则、参考范围位置等。需要覆盖不同医院、不同报告系统的格式差异。 |
| **1.4** | **正常值范围库** | **作用**：定义各种检查指标在不同人群（年龄、性别、生理状态）下的正常值范围，用于判断患者检查结果是否正常。<br>**举例**：<br>- 成人白细胞正常范围是3.5-9.5×10^9/L<br>- 0-1岁儿童白细胞正常范围是6.0-17.5×10^9/L<br>- 成人男性血红蛋白正常范围是120-160g/L<br>- 成人女性血红蛋白正常范围是110-150g/L<br>- 妊娠期女性血红蛋白正常范围是110-150g/L（与正常女性相同，但需要结合其他指标综合判断）<br>**内容组需要准备**：整理各种检查指标在不同年龄、性别、生理状态（如妊娠、哺乳等）下的正常值范围，包括：指标名称、人群分类（年龄组、性别、生理状态）、正常值下限、正常值上限、参考来源（如《临床检验参考值》等）、适用条件等。需要覆盖常见检查项目的所有主要指标。 |
| **1.5** | **异常判定规则库** | **作用**：定义什么值算正常、什么值算异常，以及异常的程度（轻度、中度、重度），并说明异常的临床意义和可能原因。<br>**举例**：对于白细胞：<br>- 正常范围：3.5-9.5×10^9/L<br>- 轻度偏低（3.0-3.5×10^9/L）：可能提示感染、营养不良、药物影响等，建议观察或进一步检查<br>- 明显偏低（<3.0×10^9/L）：需要进一步检查，排除血液系统疾病、严重感染、自身免疫性疾病等，建议尽快就医<br>- 轻度偏高（9.5-12.0×10^9/L）：可能提示感染、炎症、应激反应等，建议观察或进一步检查<br>- 明显偏高（>12.0×10^9/L）：需要进一步检查，排除严重感染、血液系统疾病、炎症性疾病等，建议尽快就医<br>**内容组需要准备**：为每个检查指标定义：<br>- 正常范围（引用正常值范围库）<br>- 异常分级标准（轻度异常、中度异常、重度异常的数值范围）<br>- 异常程度的临床意义（可能提示的疾病或状态）<br>- 异常的可能原因（常见原因列表）<br>- 处理建议（观察、进一步检查、尽快就医等）<br>- 需要关注的伴随指标（如白细胞升高时，需要关注中性粒细胞、淋巴细胞等） |
| **1.6** | **指标关联分析规则库** | **作用**：定义如何分析多个相关指标之间的关系，识别指标组合的临床意义，提供综合解读建议。<br>**举例**：<br>- 如果"白细胞"升高且"中性粒细胞"升高，提示细菌感染可能性大<br>- 如果"白细胞"升高但"中性粒细胞"正常或偏低，提示病毒感染或其他原因<br>- 如果"血红蛋白"降低且"红细胞"降低且"红细胞平均体积"降低，提示小细胞低色素性贫血，可能原因包括缺铁性贫血等<br>- 如果"转氨酶"升高且"胆红素"升高，提示肝功能损害，需要进一步检查<br>**内容组需要准备**：整理指标之间的关联关系，包括：<br>- 相关指标组合（哪些指标通常一起分析）<br>- 指标组合的典型模式（如"白细胞+中性粒细胞"、"血红蛋白+红细胞+红细胞平均体积"等）<br>- 不同模式对应的临床意义<br>- 综合解读建议（如何根据多个指标的组合给出综合判断） |
| **1.7** | **报告解读输出模板库** | **作用**：定义报告解读结果的统一输出格式，确保解读结果清晰、完整、易懂。<br>**举例**：报告解读结果应包括：<br>- 报告基本信息（检查项目、检查日期、医院等）<br>- 指标清单（所有识别的指标及其数值、单位、正常值范围、是否异常）<br>- 异常指标汇总（列出所有异常指标，标注异常程度）<br>- 临床意义解读（异常指标的临床意义、可能原因）<br>- 综合建议（是否需要进一步检查、是否需要就医、注意事项等）<br>**内容组需要准备**：设计报告解读结果的输出模板，包括：<br>- 报告基本信息结构<br>- 指标清单格式<br>- 异常指标汇总格式<br>- 临床意义解读格式<br>- 综合建议格式<br>- 不同严重程度的提示方式（如轻度异常、中度异常、重度异常的展示方式） |
