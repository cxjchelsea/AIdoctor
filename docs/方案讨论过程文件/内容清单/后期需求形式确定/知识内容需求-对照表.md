# AI医生系统-知识内容需求具体目录

---

## 对照表结构说明

- **2.1 基础层**：医学概念本体与编码规范、归一化词表、基础标准配置
- **2.2 三模板核心层**：模板A（主诉级候选集）、模板B（疾病模板）、模板C（证据条目库）
- **2.3 规则层**：入口判定与工作态切换、A路径、风险与急症识别、回填/重排/回退、入口角度统一转换
- **2.4 治理层**：版本管理与发布流程、一致性校验标准、最小验收指标

## 2 三模板核心层（核心知识内容）

### 2.1 模板A：主诉级候选集

| 实施版条目 | 知识内容名称 | 对应关系 | 说明 |
|-----------|------------|---------|------|
| 3.6 | 主诉级鉴别诊断模板库（DDx Universe） | 直接对应 | 主诉→三层候选集合（首要假设/主要备选/必须排除） |
| 3.7 | 分层规则库 | 直接对应 | 三层候选的分层规则（首要假设规则、主要备选规则、必须排除规则） |
| 3.8 | 推理子组组织规则库 | 直接对应 | 候选方向的子组组织（按系统来源/病程/诱因等维度组织） |
| 3.9 | 分流路径模板库 | 直接对应 | 分流路径（通过分叉式问诊快速区分诊断方向的关键问题序列） |
| 3.10 | 关键分岔点（Pivotal Points）清单 | 直接对应 | 关键分岔点清单（互斥的分岔点，如急性vs慢性、活动诱发vs静息发生） |

**说明**：模板A为核心内容，为每个主诉定义三层候选集合、分流路径、关键分岔点等，是系统进行候选生成的基础。
