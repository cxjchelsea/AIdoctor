# 三模板填写指南

---

## 1. 模板C：证据条目库

### 1.1 模板C的组织方式

**模板C与模板A、B的区别**：
- **模板B**：按疾病组织，一个疾病一张表（如：急性心肌梗死一张表、稳定型心绞痛一张表）
- **模板A**：按主诉组织，一个主诉一张表（如：胸痛一张表、发热一张表）
- **模板C**：按证据类型组织，**每行一个证据**（如：胸痛伴大汗一个证据、心电图ST段抬高一个证据）

**模板C的组织结构**：
- 不是按疾病或主诉分类，而是按**证据类型**分类：
  - 症状类证据（如：胸痛伴大汗、发热、腹痛）
  - 检查结果类证据（如：心电图ST段抬高、血常规异常）
  - 测量值类证据（如：体温、血压、心率）
  - 体征类证据（如：皮肤苍白、呼吸急促）
  - 人群背景类证据（如：年龄>40岁、有糖尿病史）

**为什么先填模板C？**

模板C是基础，模板A和模板B都会引用它。建议**先整理证据条目库**，再填疾病和主诉。

### 1.2 需要填什么？

#### 1.2.1 基本信息

| 字段 | 说明 | 示例 |
|------|------|------|
| **证据编号** | 唯一编号，格式：`EVID_001`、`EVID_002` | `EVID_001` |
| **证据名称** | 标准名称 | `胸痛伴大汗` |
| **同义词** | 用户可能说的其他说法 | `胸痛+出汗`、`心前区疼痛伴大汗` |
| **证据类型** | 症状/体征/测量值/检查结果/人群背景 | `症状` |
| **获取方式** | 追问/观察/设备测量/线下检查 | `追问` |

#### 1.2.2 证据出现/缺失时的作用

| 情况 | 需要说明 | 示例 |
|------|----------|------|
| **证据出现时** | 支持什么？下一步问什么？ | 支持急性心梗，下一步问"疼痛持续时间" |
| **证据缺失时** | 反对什么？ | 降低急性心梗可能性 |
| **证据不确定时** | 怎么处理？ | 继续追问，或问其他证据 |

#### 1.2.3 如果是追问证据，需要写问法

| 字段 | 说明 | 示例 |
|------|------|------|
| **标准问法** | 系统会问用户的问题 | `"胸痛时是否伴有大汗？"` |
| **问题类型** | 是否题/多选题/量表题/自由文本 | `是否题` |
| **答案选项** | 如果是选择题，有哪些选项 | `是，大量出汗` / `否，没有出汗` / `不确定` |

#### 1.2.4 如果是测量值/检查结果，需要写正常范围

| 字段 | 说明 | 示例 |
|------|------|------|
| **正常值范围** | 正常值是多少 | 体温：36.0-37.5℃ |
| **异常值解释** | 超出正常值说明什么 | `>37.5℃为发热，>39℃为高热` |

### 1.3 填写示例

**示例1：症状类证据**

```
证据编号：EVID_001
证据名称：胸痛伴大汗
同义词：胸痛+出汗、心前区疼痛伴大汗
证据类型：症状
获取方式：追问

证据出现时：
  - 作用：支持急性心梗
  - 下一步建议：问"疼痛持续时间"（EVID_002）、"疼痛位置"（EVID_003）

证据缺失时：
  - 作用：降低急性心梗可能性

标准问法："胸痛时是否伴有大汗？"
问题类型：是否题
答案选项：
  - 是，大量出汗 → 证据存在
  - 否，没有出汗 → 证据不存在
  - 不确定 → 继续追问
```

**示例2：检查结果类证据**

```
证据编号：EVID_010
证据名称：心电图ST段抬高
同义词：ECG ST elevation、ST段抬高
证据类型：检查结果
获取方式：线下检查

证据出现时：
  - 作用：强烈支持急性心梗
  - 下一步建议：问"心肌酶检查结果"（EVID_011）

正常范围：正常 = 无ST段抬高
异常值解释：ST段抬高≥1mm（两个相邻导联）提示急性心梗
```

### 1.4 批量填写流程（基于权威书籍）

**模板C的组织方式**：
- 模板C不像模板B（按疾病）或模板A（按主诉）那样有明确的目录
- 模板C是按**证据类型**组织的：症状类、体征类、检查结果类、测量值类、人群背景类
- 建议的工作流程：**先填部分模板B，从疾病中提取证据，再系统整理到模板C**

**步骤1：内容组列出证据来源清单**
- **方式1（推荐）**：先填写部分疾病模板（模板B），从疾病相关章节中提取关键证据
  - 例如：填写"急性心肌梗死"时，提取"胸痛伴大汗"、"心电图ST段抬高"等证据
  - 将这些证据整理到模板C中
- **方式2**：直接从诊断学、内科学等权威书籍的特定章节中提取
  - 症状类：从诊断学的"症状学"章节中提取常见症状
  - 检查结果类：从诊断学的"辅助检查"章节中提取常见检查结果
  - 测量值类：从诊断学的"生命体征"章节中提取

**交付物**：
- 证据来源清单（Excel）
- 列：证据类型、证据名称（初步）、来源（疾病名称/书籍章节）、书籍来源

**示例**：
| 证据类型 | 证据名称（初步） | 来源 | 书籍来源 |
|---------|----------------|------|----------|
| 症状 | 胸痛伴大汗 | 急性心肌梗死 | 内科学（第9版）第3篇第6章 |
| 检查结果 | 心电图ST段抬高 | 急性心肌梗死 | 内科学（第9版）第3篇第6章 |
| 症状 | 发热 | 诊断学症状学章节 | 诊断学（第9版）第1章 |

**步骤2：按证据类型分组，利用AI辅助填表**
- 将同一类型的证据放在一起，批量处理
- 例如：先处理所有"症状类"证据，再处理"检查结果类"证据
- 将书籍内容输入AI，使用以下提示词模板：

```
请根据以下医学书籍内容，填写证据条目：

书籍来源：[书籍名称、作者、版本、章节/页码]
书籍内容：
[粘贴书籍中关于症状/体征/检查结果的描述]

请按照以下格式填写：

1. 基本信息
   - 证据编号：[按编号规则填写，如EVID_001]
   - 证据名称：[标准名称，如"胸痛伴大汗"]
   - 同义词：[用户可能说的其他说法，用分号分隔]
   - 证据类型：[症状/体征/测量值/检查结果/人群背景]
   - 获取方式：[追问/观察/设备测量/线下检查]

2. 证据出现/缺失时的作用
   - 证据出现时：
     * 作用：[支持什么疾病或诊断方向]
     * 下一步建议：[下一步要问什么或查什么，引用其他证据编号]
   - 证据缺失时：
     * 作用：[反对什么疾病或诊断方向]
   - 证据不确定时：
     * 处理方式：[继续追问/问其他证据]

3. 如果是追问证据，需要写问法
   - 标准问法：[系统会问用户的问题]
   - 问题类型：[是否题/多选题/量表题/自由文本]
   - 答案选项：[如果是选择题，列出所有选项，并说明每个选项对应的证据值：存在/不存在/不确定]

4. 如果是测量值/检查结果，需要写正常范围
   - 正常值范围：[正常值是多少，如"36.0-37.5℃"]
   - 单位：[如有]
   - 异常值解释：[超出正常值说明什么，如">37.5℃为发热，>39℃为高热"]

注意：
- 证据名称要标准化，避免口语化表达
- 同义词要全面，覆盖用户可能的各种说法
- 如果书籍中没有明确说明证据的作用，可以根据医学常识推断，但标注"待审核"
- 追问证据必须要有标准问法，问法要通俗易懂
```

**步骤3：技术人员检查AI输出**
- 检查格式是否正确
- 检查证据名称是否标准化
- 检查问法是否通俗易懂
- 检查是否有遗漏的重要信息
- **重要**：检查是否有重复的证据（同一个证据可能有不同的表述）

**步骤4：去重和合并**
- 如果发现重复证据（如"胸痛伴大汗"和"胸痛+出汗"是同一个证据），合并为一个条目
- 将同义词统一到一个证据条目中

**步骤5：编号规则**
- 症状类：EVID_001 - EVID_500
- 检查结果类：EVID_501 - EVID_800
- 测量值类：EVID_801 - EVID_900
- 体征类：EVID_901 - EVID_950
- 人群背景类：EVID_951 - EVID_999

**步骤6：使用Excel模板整理**
- 将最终确认的内容整理到Excel模板
- **每行一个证据**（不是按疾病或主诉组织，而是按证据类型组织）
- 列：证据编号、证据名称、同义词、证据类型、获取方式、标准问法、答案选项、正常范围、异常值解释、证据出现时作用、证据缺失时作用、书籍来源

**步骤7：建立证据编号索引**
- 创建一个索引表，方便后续填写模板B和模板A时查找证据编号
- 列：证据编号、证据名称、同义词、证据类型
- 按证据名称和同义词排序，方便搜索

## 2. 模板B：疾病模板（每个病填一张表）

### 2.1 需要填什么？

#### 2.1.1 基本信息

| 字段 | 说明 | 示例 |
|------|------|------|
| **疾病编号** | 唯一编号，格式：`DISEASE_001` | `DISEASE_001` |
| **疾病名称** | 标准名称 | `急性心肌梗死` |
| **同义词** | 用户可能说的其他说法 | `AMI`、`心梗`、`心肌梗死` |
| **ICD编码** | 国际疾病分类编码 | `I21.9` |
| **系统分类** | 属于哪个系统 | `心血管系统` |
| **病理机制** | 简要说明病因 | `冠状动脉急性闭塞导致心肌缺血坏死` |
| **起病类型** | 急性/慢性/亚急性 | `急性` |
| **风险等级** | L1（极高危）/L2（高危）/L3（中危）/L4（低危） | `L1` |
| **是否必须优先排除** | 是否高危疾病，即使概率低也要先排除 | `是` |

#### 2.1.2 关键证据映射

这里要引用模板C的证据编号，不要写自由文本。

| 证据类型 | 说明 | 填写方式 |
|----------|------|----------|
| **关键阳性证据** | 支持这个病的证据 | 引用证据编号，如：`EVID_001`（胸痛伴大汗）、`EVID_002`（持续时间>30分钟） |
| **关键阴性证据** | 排除这个病的证据 | 引用证据编号，如：`EVID_010`（胸痛与活动无关） |
| **关键缺失证据** | 为了确诊，必须获取的证据 | 引用证据编号，如：`EVID_020`（心电图ST段抬高） |

**每个证据要说明**：
- 证据角色：支持性/排除性/关键性

#### 2.1.3 检查关联

| 字段 | 说明 | 示例 |
|------|------|------|
| **检查项目** | 推荐做什么检查 | `心电图` |
| **检查类型** | 诊断性/筛查性/监测性 | `诊断性` |
| **优先级** | 必须做/建议做/可选 | `必须做` |
| **检查时机** | 什么时候做 | `立即` |
| **安全边界** | 如果检查正常但症状持续，怎么办 | `若心电图正常但症状持续，需进一步检查` |

#### 2.1.4 处置关联

| 字段 | 说明 | 示例 |
|------|------|------|
| **处置名称** | 治疗/处理方式 | `抗血小板治疗` |
| **处置类型** | 药物/操作/生活方式 | `药物` |
| **适应症** | 什么时候用 | `确诊急性心梗后立即使用` |
| **禁忌症** | 什么时候不能用 | `活动性出血禁用` |
| **安全警告** | 需要注意什么 | `需监测出血风险` |

#### 2.1.5 随访关联

| 字段 | 说明 | 示例 |
|------|------|------|
| **随访类型** | 常规/紧急/按需 | `常规` |
| **随访时机** | 什么时候复查 | `出院后1周、1个月、3个月` |
| **监测指标** | 要监测哪些指标 | `心电图`、`心肌酶` |
| **红旗信号** | 出现什么情况要立即就医 | `胸痛复发`、`呼吸困难加重` |

#### 2.1.6 升级触发条件

| 字段 | 说明 | 示例 |
|------|------|------|
| **触发条件** | 什么情况下要升级风险等级 | `出现心源性休克或严重心律失常` |
| **目标风险等级** | 升级到哪个等级 | `L1` |
| **升级动作** | 系统要做什么 | `立即转诊急诊科` |

### 2.2 填写示例

**疾病：急性心肌梗死**

```
疾病编号：DISEASE_001
疾病名称：急性心肌梗死
同义词：AMI、心梗、心肌梗死
ICD编码：I21.9
系统分类：心血管系统
病理机制：冠状动脉急性闭塞导致心肌缺血坏死
起病类型：急性
风险等级：L1（极高危）
是否必须优先排除：是

关键阳性证据：
  - EVID_001（胸痛伴大汗）：关键性
  - EVID_002（持续时间>30分钟）：支持性
  - EVID_003（年龄>40岁）：支持性

关键阴性证据：
  - EVID_010（胸痛与活动无关）：排除性

关键缺失证据：
  - EVID_020（心电图ST段抬高）：必须获取，用于确诊

检查关联：
  - 心电图：诊断性，必须做，立即，安全边界：若正常但症状持续需进一步检查
  - 心肌酶：诊断性，必须做，立即

处置关联：
  - 抗血小板治疗：药物，适应症：确诊后立即使用，禁忌症：活动性出血，安全警告：监测出血风险

随访关联：
  - 随访类型：常规
  - 随访时机：出院后1周、1个月、3个月
  - 监测指标：心电图、心肌酶
  - 红旗信号：胸痛复发、呼吸困难加重

升级触发条件：
  - 触发条件：出现心源性休克或严重心律失常
  - 目标风险等级：L1
  - 升级动作：立即转诊急诊科
```

### 2.3 批量填写流程（基于权威书籍）

**步骤1：内容组列出疾病清单**
- 按系统分类列出：心血管、呼吸、消化、神经等
- 每个系统列出常见疾病
- 建议优先填写：高危疾病（L1/L2）、常见疾病
- 交付物：疾病目录清单（Excel）

**步骤2：内容组找权威书籍**
- 为每个疾病找到权威医学书籍（教材、指南、专著）
- 标注书籍来源（书名、作者、出版社、版本、章节/页码）
- 交付物：书籍来源清单（Excel）

**步骤3：技术人员拆分书籍内容**
- 将每个疾病的章节内容拆分成结构化信息：
  - 基本信息：疾病名称、同义词、ICD编码、系统分类、病理机制、起病类型
  - 临床表现：典型症状、典型体征、典型背景
  - 诊断要点：关键阳性证据、关键阴性证据、必须做的检查
  - 治疗要点：处置方式、适应症、禁忌症、安全警告
  - 随访要点：随访时机、监测指标、红旗信号
  - 鉴别诊断：易混淆疾病、鉴别要点

**步骤4：准备证据编号清单**
- 从模板C中，列出所有已填好的证据编号和名称
- 方便填写时引用和匹配

- 将拆分后的书籍内容输入AI，使用以下提示词模板：

[粘贴书籍章节内容]

请按照以下格式填写：

1. 基本信息
   - 疾病编号：[按编号规则填写，如DISEASE_001]
   - 疾病名称：[标准名称]
   - 同义词：[常见别名，用分号分隔]
   - ICD编码：[如有]
   - 系统分类：[如心血管系统]
   - 病理机制：[简要说明]
   - 起病类型：[急性/慢性/亚急性]
   - 风险等级：[L1/L2/L3/L4，根据疾病严重程度和紧急程度判断]

   - 关键阳性证据：[引用模板C的证据编号，如EVID_001;EVID_002，并说明证据角色：支持性/排除性/关键性]

  * L1（极高危）：危及生命，需要立即处理（如急性心梗、主动脉夹层）

## 3. 模板A：主诉级候选集（每个主诉填一张表）

### 3.1 需要填什么？

#### 3.1.1 基本信息

| 字段 | 说明 | 示例 |
|------|------|------|
| **主诉编号** | 唯一编号，格式：`CC_001` | `CC_001` |
| **主诉名称** | 标准名称 | `胸痛` |
| **同义词** | 用户可能说的其他说法 | `胸闷`、`胸部不适`、`心前区疼痛` |

#### 3.1.2 三层候选方向

每个主诉要列出三层候选方向：

| 层级 | 说明 | 数量建议 |
|------|------|----------|
| **Tier1（首要假设）** | 最可能的1-3个方向 | 1-3个 |
| **Tier2（主要备选）** | 常见但可能性较低的方向 | 3-5个 |
| **Tier3（必须优先排除）** | 高危疾病，即使概率低也要先排除 | 2-4个 |

**每个候选方向要填写**：

| 字段 | 说明 | 示例 |
|------|------|------|
| **疾病编号** | 引用模板B的疾病编号 | `DISEASE_001`（急性心梗） |
| **疾病名称** | 疾病标准名称 | `急性心肌梗死` |
| **入选依据** | 为什么这个方向入选 | `胸痛伴大汗、持续时间>30分钟` |
| **支持线索** | 引用模板C的证据编号 | `EVID_001`（胸痛伴大汗）、`EVID_002`（持续时间>30分钟） |
| **推进缺口** | 下一步要补哪些关键证据 | `EVID_020`（心电图ST段抬高） |
| **是否必须优先排除** | 是否高危疾病（仅Tier3） | `是` |

#### 3.1.3 推进缺口详细说明

每个推进缺口要说明：

| 字段 | 说明 | 示例 |
|------|------|------|
| **证据编号** | 引用模板C的证据编号 | `EVID_020` |
| **证据名称** | 证据名称 | `心电图ST段抬高` |
| **缺口类型** | 必须获取/建议获取 | `必须获取` |
| **获取方式** | 追问/检查 | `检查` |
| **标准问法** | 如果是追问，怎么写问题 | `"需要做心电图检查，是否已做？"` |
