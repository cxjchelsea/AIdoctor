***\*AI诊断入口判定\****

***\*P0｜入口判定模块\****

***\*Step 1｜接收用户输入\****

用户用自然语言描述本次来访目的

 

***\*Step 2｜识别用户是否“有症状/困扰”\****

系统对用户输入做一次判断：

情况 A：明确无症状

用户表达的是“健康管理/体检规划/筛查/预防”，且没有任何不适描述→ 进入 Step 4（危险信号兜底）后，准备进入健康筛查路径（A）

情况 B：存在症状/困扰

用户描述任何身体不适、异常感觉、功能变化、心理困扰等（不论轻重）→ 进入 Step 4（危险信号兜底）后，准备进入症状诊断路径（B）

情况 C：不确定/模糊/混合诉求

用户说不清是否算不适，或同时说“想体检 + 有点不舒服”

→ 进入 Step 3 做一次方向澄清

 

***\*Step 3｜方向澄清（仅对“情况C”触发一次）\****

通过最小澄清确认用户当前的主要目标是：

健康筛查/体检规划（A）或

症状咨询/问题排查（B）

澄清完成后，继续进入 Step 4

 

***\*Step 4｜危险信号检查（安全兜底，所有用户都要过一次）\****

无论用户走 A 还是 B，都必须判断是否存在危险信号：

如果命中危险信号

→ 不进入线上流程

→ 输出“优先线下就医/急诊”的安全提示（结束）

如果未命中危险信号→ 进入 Step 5 输出选路结果

***\*Step 5｜输出路径结果并跳转\****

无症状 + 无危险信号 → 进入健康筛查路径（A）

有症状/困扰 + 无危险信号 → 进入症状诊断路径（B）

危险信号命中 → 退出线上流程（安全提示）

 

***\*需求清单\****

***\*1）输入接收能力\****

支持用户用自然语言描述需求（不依赖选择题入口）

允许用户输入“混合诉求”（既想体检又有轻微不适）

***\*2）症状/困扰识别规则\****

能识别“症状/不适/困扰/异常感觉/功能变化”等表达

轻微问题也算“有困扰”，不要求严重程度

能识别“明确无症状”的表达（纯筛查/纯体检规划）

***\*3）方向澄清机制（仅一次）\****

当用户表达模糊或混合诉求时，触发一次澄清

澄清结果只能落到两类：进入 A 或进入 B

澄清后不得反复追问，避免入口卡顿

***\*4）危险信号检查机制\****

维护一份危险信号清单（红旗库）

入口判定阶段只做“是否命中”，不做解释诊断

命中后输出固定的安全提示并结束线上流程

***\*5）选路输出与跳转规则\****

输出必须明确：进入 A / 进入 B / 退出线上流程

跳转到对应路径的第一个步骤

A：进入健康筛查流程的起点

B：进入症状诊断流程的起点

***\*6）路径切换支持（防止误入）\****

若用户在 A 路径中后续出现症状描述，应允许切换到 B

 

若用户在 B 路径中明确只是想筛查，应允许切换到 A

***\*健康人筛查流程\****

***\*A1｜需求分类\****

目标：把用户需求归入四类之一，后续严格对齐分支流程

1）四选一归类需求

2）输出需求类型（1/2/3/4）

 

***\*A2｜通用最小健康档案\****

目标：采集最低必要信息，为后续建议提供依据（缺失不阻塞）

1）采集最小健康档案字段

2）输出健康档案卡 + 可选补充的缺失字段清单

 

***\*A3｜进入对应分支执行\****

目标：按需求类型进入固定分支，输出该分支的标准结果

***\*A3-1｜筛查建议分支（对应需求1）\****

目标：用户无症状，只想知道“应该做哪些筛查/多久一次”

1）补充追问（仅问会影响筛查决策的关键信息）

2）规则化生成两张清单

推荐做的筛查清单

不建议做的筛查清单

3）输出分支结果 + 下次更新时间点 + 随访节奏

***\*A3-2｜体检报告解读分支（对应需求2）\****

目标：用户无症状，但体检异常，不知道下一步怎么做

1）固定追问（保证闭环所需最小信息）

2）异常分级 → 输出下一步动作结论

复查

进一步评估

退出A路径就医

3）输出分支结果 + 随访节奏

***\*A3-3｜健康目标管理分支（对应需求3）\****

目标：用户无症状，但希望改善健康状态（减脂/睡眠/运动/精力）

1）固定追问（目标/现状/资源/周期）

2）生成可执行行动计划 + 追踪指标 + 复盘节点

3）输出分支结果 + 随访节奏

***\*A3-4｜计划性健康需求分支（对应需求4）\****

目标：用户无症状，但有明确场景任务（备孕/疫苗/差旅/材料等）

1）追问场景必要信息（场景/时间点/禁忌信息）

2）输出清单 + 时间表 + 注意事项

3）输出分支结果 + 随访节奏

 

***\*A4｜统一结果页输出\****

目标：所有分支收敛为同一种结果展示结构

1）一句话总结

2）现在建议做的事（清单）

3）暂时不建议做的事（清单）

4）下一次复查/更新时间点

5）退出A路径条件提示（出现不适/危险信号→线下评估）

 

***\*A5｜随访闭环\****

目标：给出明确随访节奏，形成流程结束点与再次进入入口

1）筛查建议：周期性更新档案

2）报告解读：按异常等级给复查/评估时间

3）目标管理：按复盘节点回访更新

4）计划性需求：按场景节点提醒更新/完成任务

 

 

***\*健康人的筛查流程（A路径）需求清单\****

***\*A1｜需求分类\****

四类需求选项文案

用户常见表达归类示例

不确定时的引导话术

 

***\*A2｜通用最小健康档案\****

健康档案采集字段清单

低信息模式兜底话术（缺失不阻塞仍能输出）

缺失字段提示与补充策略（可选）

 

***\*A3｜分支执行内容（按需求类型分别准备）\****

***\*A3-1｜筛查建议分支\****

额外追问清单（仅筛查决策关键项）

输出数量与排序规则（推荐/不推荐各输出多少条）

条件触发筛查规则库（什么条件→建议哪些筛查→大致频率/时机）

不推荐筛查清单（反过度筛查理由与替代建议）

强烈要求检查时的标准回应话术

***\*A3-2｜体检报告解读分支\****

固定追问话术（保证闭环最小信息）

指标类别清单（先高频后扩展）

异常分级动作库（复查/评估/退出A路径就医）

用户焦虑安抚话术

***\*A3-3｜健康目标管理分支\****

固定追问清单（目标/现状/资源/周期）

目标计划模板库（按目标类型复用）

追踪指标建议库（2–3个即可）

失败兜底调整话术

***\*A3-4｜计划性健康需求分支\****

固定追问清单（场景/时间点/禁忌信息）

场景清单库（清单+时间表+注意事项）

场景节点提醒规则（什么时候提醒更新）

***\*A4｜统一结果页输出\****

一句话总结模板（按需求类型）

推荐/不推荐展示话术模板

退出A路径提醒文案（出现不适/危险信号→线下评估）

***\*A5｜随访闭环\****

随访节奏规则（按需求类型）

随访提醒话术（按节点提醒用户更新/复查/复盘）
