## 一、服务概述

> **参考文档**：《AI医生系统-业务逻辑详细设计.md》

### 1.1 服务定位

- **对应模块**：多模态理解模块
- **在架构中的位置**：支持检查报告识别，为examination-service提供OCR能力
- **服务职责**：
  1. OCR识别（识别检查报告图片中的文字）
  2. 图片预处理（灰度化、二值化、去噪等）
  3. 结构化提取（从OCR结果中提取结构化数据，如指标名称、数值、单位、参考范围等）

### 1.2 输入输出

#### 1.2.1 输入数据格式和来源

**输入来源**：examination-service（检查服务）调用

**输入数据格式**：
- 图片文件（支持常见格式：JPG、PNG、PDF等）
- Multipart/form-data格式上传

**字段说明**：
- `file`：图片文件（必填）

#### 1.2.2 输出数据格式和目标

**输出目标**：examination-service（检查服务）

**输出数据格式**（参考《AI医生系统-最终输出格式规范.md》）：
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "raw_text": "血常规检查报告\n白细胞计数(WBC): 6.5 10^9/L 参考范围: 4-10\n红细胞计数(RBC): 4.2 10^12/L 参考范围: 3.5-5.5\n...",
    "structured_data": {
      "indicators": [
        {
          "name": "白细胞计数",
          "code": "WBC",
          "value": 6.5,
          "unit": "10^9/L",
          "normal_range": "4-10",
          "status": "normal"
        },
        {
          "name": "红细胞计数",
          "code": "RBC",
          "value": 4.2,
          "unit": "10^12/L",
          "normal_range": "3.5-5.5",
          "status": "normal"
        }
      ],
      "examination_type": "血常规",
      "examination_date": "2025-01-15",
      "patient_info": {
        "name": "张三",
        "age": 30,
        "gender": "男"
      }
    }
  },
  "timestamp": 1705123456789
}
```

**字段说明**：
- `raw_text`：OCR识别的原始文本
- `structured_data`：结构化数据
  - `indicators`：检查指标列表
    - `name`：指标名称
    - `code`：指标编码（LOINC/SNOMED）
    - `value`：数值
    - `unit`：单位
    - `normal_range`：参考范围
    - `status`：状态（normal/abnormal/high/low）
  - `examination_type`：检查类型
  - `examination_date`：检查日期
  - `patient_info`：患者信息

#### 1.2.3 数据流转关系

**数据流转**（参考《AI医生系统-技术架构设计-CDP数据与状态管理.md》）：
```
examination-service → ocr-service → 返回OCR识别结果
                              ↓
                      更新检查记录
```

**数据存储**：
- OCR识别结果由examination-service存储到检查记录中

### 1.3 业务价值

- **多模态支持**：支持图片格式的检查报告识别
- **自动化处理**：自动识别检查报告，减少人工录入
- **结构化提取**：将非结构化的图片转换为结构化的数据
- **提高效率**：快速处理大量检查报告

### 2.2 核心算法/方法

#### 2.2.1 图片预处理算法

**算法描述**：对上传的图片进行预处理，提高OCR识别准确率。

**实现思路**：

1. **图片格式转换**
   - 支持多种图片格式（JPG、PNG、PDF等）
   - 转换为统一格式（如PNG）

2. **图片预处理**
   - 灰度化：将彩色图片转换为灰度图
   - 二值化：将灰度图转换为黑白图
   - 去噪：去除图片中的噪声
   - 倾斜校正：校正图片倾斜
   - 对比度增强：增强图片对比度

3. **区域识别**
   - 识别文字区域
   - 识别表格区域
   - 识别图片区域

**算法复杂度**：O(n)，n为图片像素数

#### 2.2.2 OCR识别算法

**算法描述**：使用OCR引擎识别图片中的文字。

**实现思路**：

1. **OCR引擎选择**
   - 初期使用Tesseract OCR（开源、稳定）
   - 可选：PaddleOCR（中文识别效果好）
   - 可选：EasyOCR（多语言支持）

2. **文字识别**
   - 调用OCR引擎识别文字
   - 获取文字位置信息
   - 获取文字置信度

3. **结果后处理**
   - 文字纠错
   - 格式规范化
   - 去除无关字符

**算法复杂度**：O(n)，n为图片像素数

#### 2.2.3 结构化提取算法

**算法描述**：从OCR识别的文本中提取结构化数据。

**实现思路**：

1. **文本解析**
   - 识别检查报告类型（血常规、尿常规、生化等）
   - 识别报告结构（标题、表格、结论等）

2. **指标提取**
   - 使用正则表达式匹配指标名称
   - 提取指标数值
   - 提取指标单位
   - 提取参考范围

3. **数据验证**
   - 验证数值格式
   - 验证单位格式
   - 验证参考范围格式

4. **状态判断**
   - 根据数值和参考范围判断状态
   - normal：正常
   - abnormal：异常
   - high：偏高
   - low：偏低

**算法复杂度**：O(n)，n为文本长度

### 2.3 性能要求

> **参考文档**：《AI医生系统-技术架构设计-性能与评估.md》

#### 2.3.1 响应时间要求

- **OCR识别**：< 5秒（单张图片）
- **结构化提取**：< 2秒
- **目标**：< 3秒（优化后）

#### 2.3.2 并发处理能力

- **支持并发请求**：10+ 并发
- **目标**：50+ 并发（优化后）

#### 2.3.3 资源消耗限制

- **内存消耗**：< 1GB（单实例）
- **CPU消耗**：< 80%（正常负载）

### 2.4 关键技术点

#### 2.4.1 关键技术难点

1. **OCR识别准确率**
   - 难点：检查报告格式多样，识别准确率可能不高
   - 解决方案：
     - 图片预处理提高识别率
     - 使用更强大的OCR引擎（如PaddleOCR）
     - 支持多种OCR引擎，可切换使用

2. **结构化提取**
   - 难点：不同医院的检查报告格式不同，难以统一提取
   - 解决方案：
     - 支持多种报告格式模板
     - 使用规则引擎和正则表达式
     - 可选：使用NLP技术提取

3. **性能优化**
   - 难点：OCR识别耗时较长
   - 解决方案：
     - 异步处理
     - 图片压缩
     - 缓存识别结果

#### 2.4.2 技术风险及应对

| 风险 | 风险等级 | 应对措施 |
|------|---------|---------|
| OCR识别准确率低 | 高 | 图片预处理，使用更强大的OCR引擎，支持人工校正 |
| 结构化提取失败 | 中 | 支持多种报告格式，提供原始文本作为备选 |
| 性能瓶颈 | 中 | 异步处理，图片压缩，缓存结果 |
| 文件格式不支持 | 低 | 支持常见图片格式，提供格式转换 |

#### 3.2.2 响应模型定义

```python
class Indicator(BaseModel):
    """检查指标"""
    name: str  # 指标名称
    code: Optional[str] = None  # 指标编码（LOINC/SNOMED）
    value: Optional[float] = None  # 数值
    unit: Optional[str] = None  # 单位
    normal_range: Optional[str] = None  # 参考范围
    status: Optional[str] = None  # 状态（normal/abnormal/high/low）

class StructuredData(BaseModel):
    """结构化数据"""
    indicators: List[Indicator] = []  # 检查指标列表
    examination_type: Optional[str] = None  # 检查类型
    examination_date: Optional[str] = None  # 检查日期
    patient_info: Optional[Dict[str, Any]] = None  # 患者信息

class OCRResponse(BaseModel):
    """OCR识别响应"""
    raw_text: str  # 原始文本
    structured_data: StructuredData  # 结构化数据
```

#### 3.2.3 数据验证规则

**遵循API接口规范**：
- 文件大小限制：< 10MB
- 支持的文件格式：JPG、PNG、PDF
- `raw_text`：必填，字符串
- `structured_data`：可选，如果提取失败则返回空结构
