# 知识图谱结构搭建使用指南

> **目标**：搭建知识图谱的基本结构（Schema），包括约束和索引  
> **创建日期**：2026-01-28  
> **文档版本**：v1.0

---

## 📋 概述

在导入数据之前，必须先搭建知识图谱的基本结构（Schema）。这包括：

1. **唯一性约束**：确保 `display_id` 和 `uuid` 的唯一性
2. **索引**：提升查询性能

---

## 🚀 快速开始

### 方式1：使用CLI脚本（推荐）

```bash
# 进入项目目录
cd knowledge-management-service

# 执行结构搭建脚本
python scripts/setup_schema.py --password your_password
```

**参数说明**：
- `--uri`: Neo4j连接URI（可选，默认从配置读取）
- `--user`: Neo4j用户名（可选，默认从配置读取）
- `--password`: Neo4j密码（必需）

**示例**：
```bash
# 使用默认配置
python scripts/setup_schema.py --password password

# 指定完整参数
python scripts/setup_schema.py \
  --uri bolt://localhost:7687 \
  --user neo4j \
  --password password
```

### 方式2：通过API接口

```bash
# 1. 启动服务
uvicorn app.main:app --host 0.0.0.0 --port 8094

# 2. 调用API搭建结构
curl -X POST http://localhost:8094/api/v1/schema/setup

# 3. 验证结构
curl http://localhost:8094/api/v1/schema/validate
```

## 📝 详细步骤

### 步骤1：准备环境

确保Neo4j已启动并可以连接：

```bash
# 检查Neo4j是否运行
docker ps | grep neo4j

# 或启动Neo4j（如果未启动）
docker run -d \
  --name neo4j \
  -p 7474:7474 -p 7687:7687 \
  -e NEO4J_AUTH=neo4j/password \
  neo4j:5.15
```

### 步骤2：配置环境变量

创建或更新 `.env` 文件：

```env
NEO4J_URI=bolt://localhost:7687
NEO4J_USER=neo4j
NEO4J_PASSWORD=password
```

### 步骤3：执行结构搭建

```bash
python scripts/setup_schema.py --password password
```

## ⚠️ 注意事项

1. **必须先搭建结构**：在导入数据之前，必须先执行结构搭建
2. **幂等性**：脚本使用 `IF NOT EXISTS`，可以安全地重复执行
3. **连接失败**：如果连接Neo4j失败，请检查：
   - Neo4j是否已启动
   - 连接URI、用户名、密码是否正确
   - 防火墙设置是否允许连接

## 🐛 故障排除

### 问题1：连接失败

**错误信息**：
```
❌ 结构搭建失败: Unable to connect to Neo4j
```

**解决方案**：
1. 检查Neo4j是否运行：`docker ps | grep neo4j`
2. 检查连接URI是否正确
3. 检查用户名和密码是否正确

### 问题2：约束已存在

**错误信息**：
```
⚠️  约束 symptom_display_id 创建失败: Constraint already exists
```

**解决方案**：
- 这是正常的，脚本使用 `IF NOT EXISTS`，已存在的约束会被跳过
- 如果确实需要重新创建，需要先删除现有约束

### 问题3：权限不足

**错误信息**：
```
❌ 结构搭建失败: Access denied
```

**解决方案**：
- 确保使用的Neo4j用户有创建约束和索引的权限
- 默认的 `neo4j` 用户应该有这些权限
