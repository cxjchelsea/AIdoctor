# 知识图谱结构管理 - 使用说明

## 功能概述

知识图谱结构管理页面提供了可视化的界面来管理Neo4j知识图谱的结构（约束和索引）。

## 访问方式

1. 启动前端管理服务：
   ```bash
   cd frontend-admin
   npm run dev
   ```

2. 访问页面：
   - 打开浏览器访问：http://localhost:3001
   - 在左侧菜单选择"知识图谱结构"

## 功能说明

### 1. 搭建结构

**功能**：创建所有约束和索引

**操作**：
- 点击"搭建结构"按钮
- 系统会自动创建所有约束和索引
- 如果约束或索引已存在，会被跳过（使用 `IF NOT EXISTS`）

**创建的约束**：
- 9个 display_id 唯一性约束
- 8个 uuid 唯一性约束
- 共17个约束

**创建的索引**：
- 9个常用查询字段索引（name、category、icd10_code等）

### 2. 验证结构

**功能**：验证当前知识图谱的结构是否完整

**操作**：
- 点击"验证结构"按钮
- 系统会检查约束和索引的数量
- 页面加载时会自动执行验证

**验证内容**：
- 约束数量
- 索引数量
- 缺失的约束
- 验证状态（通过/未通过）

### 3. 查看结果

**验证结果统计**：
- 约束数量
- 索引数量
- 验证状态
- 缺失约束列表

**搭建结果**：
- 成功创建的约束列表
- 创建失败的约束列表
- 成功创建的索引列表
- 创建失败的索引列表
- 错误信息（如果有）

## 界面说明

### 操作区域
- **搭建结构**：执行结构搭建操作
- **验证结构**：验证当前结构状态
- **刷新**：清除结果并重新验证

### 验证结果卡片
显示当前结构的验证状态和统计信息

### 搭建结果卡片
显示最近一次搭建操作的详细结果

### 约束/索引列表
以表格形式展示所有约束和索引及其状态

## 注意事项

1. **必须先搭建结构**：在导入数据之前，必须先执行结构搭建
2. **幂等性**：可以安全地重复执行搭建操作
3. **Neo4j连接**：确保Neo4j服务已启动并可连接
4. **API服务**：确保知识库管理服务（端口8094）正在运行

## 故障排除

### 问题1：连接失败

**错误信息**：`搭建失败: Network Error`

**解决方案**：
1. 检查知识库管理服务是否运行（端口8094）
2. 检查Neo4j是否运行
3. 检查API代理配置（`vite.config.ts`）

### 问题2：验证失败

**错误信息**：`验证失败: ...`

**解决方案**：
1. 检查Neo4j连接配置
2. 检查Neo4j服务是否正常运行
3. 查看浏览器控制台的详细错误信息

### 问题3：约束已存在

**现象**：搭建时提示约束已存在

**说明**：这是正常的，脚本使用 `IF NOT EXISTS`，已存在的约束会被跳过
